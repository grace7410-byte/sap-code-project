# 1차 중간평가 통합 프로그램 스펙서 (Program Specification)

## [Index 01] PM / LE (Member 1)

### 1. 자재 운송 소요 계획 조회 프로그램 (ZRB1SD0006)
* **구분**: 조회
* **Description**: 물류센터 관점에서 월별 출고 예정량 및 운송 요청량을 파악하여 본사에 자재 운송 요청을 전송하는 프로그램
* **핵심 기능**:
    * 변동 판매량에 대응하기 위해 DYNAMIC TABLE(`LVC_T_TABLE`) 구조 적용 및 필드 카탈로그 개수 동적 제어
    * CDS View 기반 월별 판매량·운송 요청량 취합 및 월별 재고량 공식 산출 대입
    * 시각화 고도화: 음수 데이터 적색 강조, 자재/저장창고별 구분선(청색) 및 가운데 정렬/볼드 처리
    * Hotspot 인터페이스: 출고 예정량 클릭 시 주문관리 프로그램으로 이동, 운송 필요량 클릭 시 운송 요청 프로세스 동적 수행
    * Dropdown List를 이용한 자재 간 즉시 이동(`SET CURSOR`) 기능 구현
* **관련 테이블**: 주문 관리 헤더/아이템 테이블, 자재 재고 테이블, 운송 요청 테이블, 월별 소요 취합 CDS View

### 2. 서비스 오더 생성 및 조회 프로그램 (SAPMZB1MM0005)
* **구분**: 트랜잭션
* **Description**: 서비스오더 생성 및 구매 정보 참조, 운송 경로와 현황을 시각화 관리하는 프로세스 통합 프로그램
* **핵심 기능**:
    * Dropdown List 조건 변경에 따른 구매/서비스 조회·생성 Subscreen 동적 분기 처리
    * `CL_GUI_PICTURE` 컨트롤러 활용, Custom Container 내 운송 경로 관련 이미지/아이콘 동적 생성 및 상세 지도 팝업 구현
    * 유효성 검증: 구매업체와 운송업체의 국가코드 불일치 시 에러 메시지 팝업 처리
    * Tabstrip 기반 구매 자재 정보 및 운송업체 레이아웃 이원화 조회
    * 데이터 연동: 운송 현황이 '원유 입고~플랜트 입고' 구간일 때 서비스 엔트리 생성 버튼 활성화 및 관련 프로그램 메모리 ID 이동 처리
* **관련 테이블**: 구매오더 헤더/아이템 테이블, 운송 현황 테이블, 국가별 운송 경로 마스터 테이블, Service Entry 항목 테이블

## [Index 02] CO (Member 2)

### 1. 공정 계획/실적 비교 분석 프로그램 (ZRB1CO0007)
* **구분**: 조회
* **Description**: 생산 공정별 계획 비용과 실제 발생 비용 데이터를 비교 분석하여 변동 시각화 및 의사결정을 지원하는 프로그램
* **핵심 기능**:
    * Screen 1000 기반 데이터 선조회 및 화면 Splitter 좌(소스 ALV 상하 배치)/우(비교 및 결과 ALV) 구성
    * 좌측 소스 행 더블클릭 시 우측 상단 현재 선택 슬롯 ALV로 데이터 이동 및 결과물ID(OUTMT) 일치 여부 LED 아이콘 제어
    * 비교 실행 시 17개 핵심 원가 항목에 대한 계획-실적 차이 금액 및 차이율(%) 자동 산출
    * 데이터 동적 연동: [새로고침] 실행 시 PP 모듈(`ZTB1PP0013`)에 추가된 신규 공정 데이터를 CO 마스터로 실시간 흡수 및 ALV 자동 반영 (PP 연계 예정)
    * 결과 엑셀 내보내기 기능 표준 구현
* **관련 테이블**: 공정 계획 비용 테이블 (`ZTB1CO0005`), 공정 실적 비용 테이블 (`ZTB1CO0006`), 생산 공정 마스터 연계 테이블 (`ZTB1PP0013`)

### 2. 원가 계산 및 등록 프로그램 (ZRB1CO0003)
* **구분**: 트랜잭션
* **Description**: 계획 및 실적 비용 소스를 기반으로 정유 공정별 단위원가를 자동 계산하고 일별 누적 등록 및 변동 추이 그래프를 구현한 프로그램
* **핵심 기능**:
    * Screen 100 입력 조건 세팅 및 전일 원가 기준일(오늘-1일) 자동 계산 필드 구현
    * 임시 원가 ALV 내 당일 단위원가(`DAYUC`) 인라인 편집 모드(`EDIT = 'X'`) 활성화 및 수정 시 최종 단위원가(`UNTAM`) 실시간 재계산 로직 구축
    * **2패스 원가 계산 로직**:
        * Pass 1 (1차 공정): `(원유비 + 1차공정비 + 촉매비) * 수율 / 100` 계산을 통한 반제품 생산원가(`SFAMT`) 및 당일 단위원가 산정
        * Pass 2 (2차 공정): 1차 반제품원가(`SFAMT`)를 후속 공정 소스로 흡수하여 `SFAMT + 2차공정비` 기준으로 최종 산출
    * 이동평균 개념 적용: 당일 원가와 전일 원가의 평균값으로 최종 단위원가(`UNTAM = (DAYUC + PREVU) / 2`) 생성
    * 이중 팝업 제어: 동일 일자/제품 데이터 존재 시 신규 버전 생성 여부 확인 팝업(Screen 200/300) 구현 및 원가 상세 테이블(`ZTB1CO0008`) 내 3개 라인 아이템(당일, 전일, 최종) 자동 분기 저장
    * 시각화: 수동 저장되지 않은 당일 데이터 존재 시 경고 팝업 가동, 우측 영역 날짜별 최종 단위원가 꺾은선 그래프(차트 컨트롤) 동적 구현
* **관련 테이블**: 공정 계획 비용 테이블 (`ZTB1CO0005`), 공정 실적 비용 테이블 (`ZTB1CO0006`), 반제품/완제품 원가 테이블 (`ZTB1CO0007`), 제품원가 결과 상세 테이블 (`ZTB1CO0008`)

## [Index 03] MM (Member 3)

### 1. 최적 원유 기반 구매오더 통합 관리 프로그램 (SAPMZB1MM0004)
* **구분**: 트랜잭션
* **Description**: 외부 피오리 시스템의 최적 원유 조건 데이터와 연동하여 구매오더의 CUD 및 수율 기반 의사결정을 통합 제어하는 프로그램
* **핵심 기능**:
    * 사용자 편의 기능: 최초 실행 시 가이드 팝업 자동 오픈 제어 및 '오늘 하루 이 창 열지 않기' 쿠키 로직 구현
    * 비즈니스 데이터 연동: BP 마스터 및 공급업체 정보 ALV 핫스팟 연동, 벤더 선택 시 구매 가용한 원유 데이터로 탭스트립 내 '공급업체별 자재 선택' ALV 스크린 동적 전환
    * 구매오더 아이템 유효성 체크: 최적화 자재 여부 검증 및 불일치 자재 입력 시 경고 메시지 출력과 단가·단위 자동 할당 차단 알고리즘 구현
    * 다차원 시각화 탭스트립:
        * TAB 1: 호출 시점 환율 연동 외화-원화 자동 환산 ALV 구성 및 유종별 연산품 수율 조회 드롭다운 차트 연동
        * TAB 2: 계절 가중치 반영 원유 수율 데이터 ALV 및 차트 동시 출력 처리
    * 트랜잭션 제어: 저장 전 '오류 확인' 유효성 검증 버튼 구현, 저장 시 총액 재확인 팝업 가동 및 문서유형 'SV' 전환 시 서비스오더 프로그램으로 메모리 ID 전달 후 자동 화면 전환(`SET PARAMETER / CALL TRANSACTION`)
    * 결재 프로그램 연계 인터페이스 및 헤더(단건)/아이템(ALV 가변 EDIT 모드) 수정·삭제 다건 트랜잭션 스크린 구축
* **관련 테이블**: 구매 최적화 조건 테이블 (`ZTB1MM0005`), 구매오더 헤더/아이템 테이블 (`ZTB1MM0006`, `ZTB1MM0007`), 공급업체/자재 마스터 관련 테이블

### 2. 정유 부피측정 통합 조회 및 오더 역추적 프로그램 (ZRB1MM0001)
* **구분**: 조회
* **Description**: 온도, 밀도 등 환경 변수에 따른 환산 부피 실측 데이터를 기반으로 구매·판매·생산 전사 오더의 흐름을 역추적하는 물류 제어 프로그램
* **핵심 기능**:
    * Selection-screen 내 오더 유형, 자재, 플랜트 등 전 필드 서치헬프 적용을 통한 입력 오류 원천 차단
    * Splitter 컨테이너 및 `CL_DD_DOCUMENT` 활용, 선택 조건 텍스트 래핑 출력 및 선택 오더 유형에 따른 동적 `LEFT OUTER JOIN` 인덱스 검색 구현
    * 성능 최적화: `SELECT *` 지양 및 필요한 필드 선별 추출, 필드 심볼(`FIELD-SYMBOLS`)을 활용한 대량 데이터 가공 속도 최적화 및 미부합 데이터 딜리트 플래그 전 처리 메모리 절감
    * 물류 단계 자동 판별: 측정번호 유무 및 수량 징후(양수/음수) 분석을 통해 입고(GR)/출고(GI) 단계를 시스템이 자동 판별하여 텍스트 출력
    * 가독성 개선: 측정 상태별 아이콘 및 셀 색상 제어(`LVC_S_SCOL`) 구현, 상단 컨테이너에 `add_link` 이벤트를 결합한 시각적 물류 상태 바(오더-부피측정-입고) 구축 및 링크 클릭 시 후속 문서 역추적 화면 호출
    * 계층형 뷰 구조화: `REUSE_ALV_HIERSEQ_LIST_DISPLAY`를 사용하여 오더 헤더와 자재 상세 아이템 간의 1:N 관계를 단일 스크린에 구현, 측정 완료 건 대상 자동 확장(`EXPAND`) 설정 및 대기 상태 품목 즉각 식별 구조화
* **관련 테이블**: 부피측정 테이블 (`ZTB1MM0020`), 구매오더 헤더/아이템, 판매오더 헤더/아이템, 생산계획 오더 헤더/아이템, 자재이동 문서 테이블 일체
