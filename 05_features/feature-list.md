## 💡 모듈 간 통합 비즈니스 연동 포인트 (4/29 기준 반영)
1. **MM(03) ➡️ MM(01) 연동**: `SAPMZB1MM0004` 구매오더 프로그램에서 문서유형을 서비스오더(`SV`)로 변경하거나 저장 완료 시, `SAPMZB1MM0005` 서비스 오더 프로그램으로 메모리 ID를 전달하며 화면이 동적으로 즉시 전환됨.
2. **MM(03) 🔄 전사 물류**: 부피측정 프로그램(`ZRB1MM0001`) 조회 시 사용자가 선택한 오더 유형에 따라 MM(구매), SD(판매), PP(생산)의 CBO 테이블들을 실시간으로 분기 판별하여 동적 조인을 수행하고, 후속 자재이동 문서까지 역추적 체계를 연결함.
3. **PP(04) ➡️ CO(02) 연동**: 공정 계획/실적 비교 프로그램(`ZRB1CO0007`)에서 새로고침 수행 시 PP 모듈의 신규 공정 데이터 변동분(`ZTB1PP0013`)을 실시간 검증하여 CO 테이블 데이터로 자동 추가 적재하는 인터페이스 연동 구조 확보.
4. **PP(04) ➡️ MM/FI 연동**: 자재 소요량 계획(`ZRB1PP0004`) 실행에 따라 최종 저장 처리된 소요 결과 테이블 데이터를 MM의 가용 재고 및 FI의 제조 원가 전표 생성 소스로 참조 연계 처리함.
5. **FI(05) 🔄 전사 물류/원가 연동**: 물류/판매 연동 프로그램(`ZRB1FI0004`)과 생산/원가 연동 프로그램(`ZRB1FI0003`)은 타 모듈(MM, SD, PP, CO)의 헤더/아이템 테이블 핵심 데이터를 단일 스크린에 동적 바인딩하여 복식부기 전표 생성을 제어함.
