# LE 모듈 서비스 PO 생성 프로그램 상세 설계
Date: 2026-04-23
담당: LE (Member 1)

## 1. UI/UX 제어 요약
* **버튼 제어**: 최적화 데이터 및 수율 차트 버튼 속성 비활성화(숨김) 처리.
* **텍스트 번호**: Screen 상에 텍스트 번호 인풋 필드 반영.
* **안내 스크린**: 서비스 오더 생성 프로그램 가이드 화면 링크 및 안내 UI 추가.

## 2. 화면 로직 및 유효성 검증 (Validation)
* **공급업체 변경 이벤터(Enter)**:
* 공급업체 변경 후 Enter 이벤트 발생 시, 별도 정의된 국가코드 마스터 기반으로 Search Help 제한 (해당 국가에 속한 BP 목록만 노출).
* 입력된 공급업체의 국가코드가 마스터 정의와 불일치할 경우 에러 메시지 팝업 및 프로세스 락.
* **자동 마스터 맵핑**: 공급업체 확정 시 구매조직, 구매그룹, 회사코드, 지급조건 데이터 자동 변경 및 화면 리프레시.

## 3. 동적 탭스트립(Tabstrip) 구조
PBO 시점에 `GV_SAVE_CHECK = 'X'` 검증 후 하단에 2개 탭 동적 생성.

### 탭 1: 서비스
* 기존 일반 PO 아이템 데이터 및 금액 정보 자동 호출 및 화면 매핑.
* 서비스 아이템 데이터 추가 입력 레이아웃 구성.

### 탭 2: 경로
* 국가 코드별 운송 경로 마스터 연동 (CDS View를 활용하여 BP 코드와 조합 후 dynamic 조회).
* 날짜 필드 제어: 현재 날짜(`SY-DATUM`) 기준 자동 입력 처리.
* 운송 요청일 계산: 국가별 마스터에 정의된 경로별 소요 일수(Lead Time)를 계산하여 운송 요청 날짜에 동적 가산 처리.
