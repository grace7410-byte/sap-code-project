# C-nergy AS-IS / TO-BE Process Analysis

**Date:** 2026-03-17 ~ 2026-03-19

**Updated:** 2026-07-15 (Final Refinement)

## 1. 수입 물류 및 대금 정산 (Procurement & FI)
- **AS-IS Process**
  - 원유 수입 시 해상 운송 기간(약 45일) 동안 장부상 재고 파악 불가능.
  - 온도 변화에 따른 원유 부피 변동을 시스템에 반영하지 못해 실재고와 장부 간 오차가 상시 발생하며, 수기 및 바코드 관리 미비로 전산 반영 시차 발생.
  - 입고 후에만 송장 검증이 가능하여 대금 지급 시점과 실물 인식 시점의 괴리 발생.
- **TO-BE Process**
  - **선적 입고(In-transit GR) 기반 장부 선반영**: 15℃ 표준 환산 부피(Net Volume) 기준 선적 시점에 재고를 즉시 인식하고, 송장 검증(IV) 및 대금 지급 프로세스 가속화.
  - **바코드 연동 실측 및 증발 로스(Internal Loss) 분리**: 모바일/바코드 기반 부피 측정으로 입고 수량을 전산에 즉시 연동하고, 선적 수량과의 차이는 시스템이 감지하여 내부 손실 전표로 자동 정산.

## 2. 수요 대응 및 물류센터 유통 관리 (Depot & SD)
- **AS-IS Process**
  - 본사에서 물류센터 재고를 수동 배정하거나 엑셀/메일 기반으로 요청을 주고받아 전표 생성 시차 발생.
  - 국제유가 및 환율 변동을 실무자가 수기로 입력하여 판매 가격 반영에 지연이 발생하고, 거점별 실시간 가용 재고(ATP) 확인 불투명.
- **TO-BE Process**
  - **표준 API 기반 유가/환율 실시간 반영**: 외부 API 인터페이스를 통해 환율과 MOPS 국제유가를 자동 적재하여 제품 판매가 산정 지연 해소.
  - **재고 보충 요청(DR) 및 수요 역산 시스템**: 물류센터 가용재고 기반 보충 요청 -> 본사 승인 시 즉시 재고 이동 및 PIR(계획독립수요) 역산 반영.

## 3. 생산 실적 및 정밀 원가 정산 (PP & CO)
- **AS-IS Process**
  - 표준 BOM 기반의 고정 수율로 원가를 산출하여 실제 정유 공정의 변동 수율 및 환율 변동을 반영하지 못함.
  - 공정-운송-세금 등 부서별 비용이 연계되지 않고 사후 집계되어 제품별 정밀 수익성 파악 불가능.
- **TO-BE Process**
  - **품질 기반 전처리 및 실측 데이터 반영**: 원유 염분 수치 판정에 따른 전처리 공정 유무 반영 및 생산 오더(예측) 대 실제 자재 이동(실측) 데이터 이원화 관리.
  - **제품별 맞춤 공정 원가 자동 배부**: 자재 이동 시점의 환율 데이터 및 연산품 수율 기준 공정 비용을 자동 배부하여 실시간 원가 차이(Variance) 및 CO 수익성 분석 완료.

## 4. 데이터 연계 및 관리 체계 (System Migration)
- **AS-IS Process**
  - SAP 도입 이전 데이터 관리 미흡으로 부서별 양식과 관리 방식이 상이하여 마이그레이션 중 오류 발생.
  - 전표 생성 시 검토 누락 및 입력 실수로 인한 관리 리스크 상존.
- **TO-BE Process**
  - **전표 자동화 및 자동 연계**: 자산-부채-자본의 변경 마다 전표를 자동 발행하여 부서간 데이터 연계성 확보.
  - **Search Help 기반 수동 전표 제어**: 필수 수동 전표 작성 시 Search Help를 적용해 입력 오류 방지 및 검토 절차 표준화.

## 5. 통합 비즈니스 플로우 (Integrated To-Be)

**[Procurement]** 원유 PO 생성 → 선적 입고(15℃ 환산) → 송장 검증/지급 → 플랜트 입고(바코드 연동/로스 정산) → 염분 판정/전처리


**[Production & CO]** 수요 예측 → 생산 오더(예측) → 원자재/반제품 실측 투입 → 수율 기반 공정비 자동 배부 → 원가 차이 분석


**[Logistics & Sales]** 유가/환율 API 적재 → 거점 재고 모니터링 → 보충 요청(DR) → PIR 역산 반영 → 출하 및 자동 전표 생성
