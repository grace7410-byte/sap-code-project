# C-nergy AS-IS / TO-BE Process Analysis

Date: 2026-03-17 ~ 2026-03-19
Updated: 2026-04-03

## 1. 수입 물류 및 대금 정산 (Procurement & FI)
- **AS-IS Process**
  - 원유 수입 시 해상 운송 기간(약 45일) 동안 장부상 재고 파악 불가.
  - 입고 후에만 송장 검증이 가능하여 대금 지급 시점과 실물 인식 시점의 괴리 발생.
- **TO-BE Process**
  - **선적 입고(In-transit GR) 기반 장부 선반영**: 선적 시점에 재고를 인식하고 송장 검증(IV)을 완료하여 대금 지급 프로세스 가속화.
  - **증발 로스(Internal Loss) 분리**: 선적 수량과 플랜트 입고 수량의 차이를 시스템이 자동 감지하여 내부 손실로 별도 정산.

## 2. 물류센터 및 유통 관리 (Depot & SD)
- **AS-IS Process**
  - 본사에서 물류센터 재고를 수동으로 배정하거나 엑셀/메일 기반으로 요청을 주고받아 전표 생성 시차 발생.
  - 거점별 실시간 가용 재고(ATP) 확인이 어려워 긴급 수요 대응력 저하.
- **TO-BE Process**
  - **재고 보충 요청(DR) 시스템**: 물류센터 수요 예측(FC) 기반 자동 보충 요청 -> 본사 승인 시 즉시 재고 이동 및 FI 전표 연동.
  - **Pull 방식 물류 전략**: 물류센터의 실재고 기반으로 본사 출하를 트리거하여 불필요한 재고 적체 방지.

## 3. 생산 실적 및 원가 산출 (PP & CO)
- **AS-IS Process**
  - 표준 BOM 기반의 고정 수율로 원가를 산출하여 실제 정유 공정의 변동 수율을 반영하지 못함.
  - 투입 대비 산출 데이터가 사후에 집계되어 실시간 원가 차이 분석 불가능.
- **TO-BE Process**
  - **생산 실적 데이터 이원화**: 생산 오더는 '예측'치로 생성하되, 실제 자재 이동(101/261)은 직접 입력한 '실측'치로 생성.
  - **수율 차이(Variance) 실시간 도출**: 오더 번호를 키로 계획과 실적을 매핑하여 공정별 원가 차이를 즉각 분석.

## 4. 재고 정확성 및 환경 보정 (Inventory)
- **AS-IS Process**
  - 온도 변화에 따른 원유 부피 변동을 시스템에서 처리하지 못해 장부와 실재고 간 오차 상시 발생.
- **TO-BE Process**
  - **15℃ 환산 수량(Net Volume) 관리**: 온도/밀도 보정 로직을 적용하여 국제 표준 수량으로 재고 가치를 일원화.

## 5. 통합 비즈니스 플로우 (Integrated To-Be)

**[Procurement]** 원유 PO 생성 → **선적 입고(재고 인식)** → 송장 검증 → 대금 지급 → 플랜트 입고(로스 정산)
**[Production]** 수요 예측(FC) → 생산 오더(예측) → 원유 투입/산출(실측) → **수율 차이 분석** → 결산
**[Logistics]** 거점 재고 모니터링 → **보충 요청(DR)** → 본사 승인 → 재고 이동 → 판매 및 출하
