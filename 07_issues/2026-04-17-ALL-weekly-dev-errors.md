# [Anvil Integrated Issue Log] 2026-04-17 전사 통합 개발 이슈 모음집

목적: 전사 모듈(MM/SD/PP/FI/CO) 구현 과정에서 발생한 모든 기술적 오류, 시스템 버그 및 트러블슈팅 내역을 한 번에 통합 관리함.
1) 발생현상, 2) 해결 방안 및 조치 순으로 기재.

---

## [Issue #1] 동적 ALV 컴포넌트 제어 시 Field Symbol 참조 할당 덤프 오류 (MM) <a id="issue-1"></a>

### 1) 발생 현상
- 런타임 환경에서 구조가 결정되는 동적 ALV(Dynamic ALV Grid) 인터페이스 생성 과정 중, 동적으로 빌드된 내부 테이블(ITAB)의 포인터를 핸들링하는 Field Symbol 구문이 정상적으로 메모리 주소를 할당받지 못한 상태에서 데이터 컴파일이 실행되어 시스템 단에서 덤프(Dump) 예외가 발생하는 현상 발생.

### 2) 해결 방안 및 조치
- 런타임 에러 방지를 위해 데이터 가공 단계별로 디버깅을 수행하여 Field Symbol 구문이 지시 대상 테이블에 완벽히 바인딩(`IS ASSIGNING`)되었는지 검증 분기문을 구축하였으며, 개별 루프 및 서브루틴 로직의 연산 처리가 종결되는 시점에 명확히 `UNASSIGN` 제어 처리를 수행하여 메모리 잔상 충돌 현상 조치 완료.

---

## [Issue #2] 데이터 추가 후 이전 데이터 더블클릭 및 버튼 재작동 시 튕김 현상 (CO) <a id="issue-2"></a>

### 1) 발생 현상
- 데이터가 추가된 뒤 이전 데이터를 더블클릭하고 버튼을 다시 누르면 튕기는 현상 발생.

### 2) 해결 방안 및 조치
- 추후 업데이트 예정.

---

## [Issue #3] DATA_CHANGED 이벤트 내 SCREEN-INPUT 변경 시 비활성화 미반영 현상 (MM) <a id="issue-3"></a>

### 1) 발생 현상
- handle_data_changed 이벤트 내에서 화면 속성(SCREEN-INPUT) 변경 시, PBO 를 다시 타지 않아 비활성화 처리가 즉시 반영되지 않는 현상 발생.

### 2) 해결 방안 및 조치
- 강제 PAI 호출(SET OK_CODE) 로 1 차 해결. 이후 데이터 변경 플래그를 활용하여 PBO 에서 화면 속성이 제어되도록 구조 개선.

---

## [Issue #4] 마스터 데이터 누락에 따른 원화 환산 처리 불능 오류 (MM) <a id="issue-4"></a>

### 1) 발생 현상
- 환율 데이터가 누락되어 원화 환산이 불가한 문제 발생.

### 2) 해결 방안 및 조치
- CDS View 환율 유형(KURST) 필드의 데이터 타입과 조인 조건값('M')의 불일치임을 확인하여 수정함.

---

## [Issue #5] 사용자 정의 서브루틴 미호출로 인한 아이템 번호 갱신 유실 (MM) <a id="issue-5"></a>

### 1) 발생 현상
- 사용자 정의 채번 로직(set_item_number)이 자동 호출되지 않아 아이템 번호가 갱신되지 않는 현상 발생.

### 2) 해결 방안 및 조치
- after_user_command 등 표준 액션 이후 시점을 포착하여 채번 로직을 강제 수행함으로써 실시간 아이템 번호 정합성 확보.

---

## [Issue #6] F4 도움말 트리거 시 불필요한 입력값 제안 현상 (PP) <a id="issue-6"></a>

### 1) 발생 현상
- F4 를 통한 입력값 제안에 불필요한 내용까지 나타나는 현상 발생.

### 2) 해결 방안 및 조치
- DROP DOWN 내용을 DB 에서 가져온 값을 가공해 제공함.

## [Issue #7] 예외 검증 로직 내 탈출 조건 유실로 인한 런타임 DUMP 오류 (PP) <a id="issue-7"></a>

### 1) 발생 현상
- 유효한 선택 값이 있는지는 확인했으나 탈출 코드가 없어서 DUMP 가 발생하는 현상 발생.

### 2) 해결 방안 및 조치
- 탈출 코드를 추가해 덤프가 발생하기 전에 종료하도록 개선함.

---

## [Issue #8] 서브스크린 초기화 유실에 따른 실행 시점 런타임 덤프 오류 (FI) <a id="issue-8"></a>

### 1) 발생 현상
- 버튼 제어 시점에 서브스크린이 호출되어야 하나, 메인 프로그램 실행 직후 서브스크린이 비정상 트리거되면서 시스템 덤프가 발생하는 현상 발생.

### 2) 해결 방안 및 조치
- 가상의 빈 서브스크린 객체를 명시적으로 생성하여 레이아웃에 마운트하였으며, PBO 단에서 초기값을 안정적으로 정착하도록 제어 코드 설정함.

---

## [Issue #9] ALV 필터링 적용 시 런타임 인덱스 불일치 및 데이터 미동기화 오류 (SD) <a id="issue-9"></a>

### 1) 발생 현상
- 헤더 ALV 에 필터를 적용한 상태에서 아이템 ALV 로딩 시, 필터링된 데이터 셋의 인덱스가 누락되어 선택한 판매오더가 아닌 엉뚱한 마스터 정보가 화면에 호출되는 현상 발생.

### 2) 해결 방안 및 조치
- 데이터 인덱스 포인터 충돌을 방지하기 위해 필터 이벤트가 트리거되는 시점마다 DB 단에서 SELECT 구문을 재수행하여 신규 버퍼 데이터를 완전 재바인딩하는 구조로 로직 변경 해결.
