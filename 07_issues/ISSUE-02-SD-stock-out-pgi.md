# [Issue] PGI(출고 전기) 시 실물 재고 부족 오류

Date: 2026-03-20
- Status: Resolved
- Module: SD/MM

## 발생 상황
- `VL02N`(출하 변경)에서 Picked Qty를 입력했으나, **PGI(Post Goods Issue)** 버튼 클릭 시 재고 부족 에러 발생으로 인해 전표 확정 불가.

## 원인 분석
- 자재 마스터 상에 이름만 존재하고 실제 창고(Plant 1010 / SLoC 101A)에 물리적인 재고가 0인 상태.
- 연습 서버 환경에서 가용성 점검(ATP)이 경고만 주고 주문 생성을 허용했으나, 실제 출고 시점에는 실물 재고가 반드시 필요함.

## 해결 방법
- **MIGO(이동 유형 561)를** 사용하여 초기 재고를 강제 등록함.
    - [A01 입고] / [R10 기타] 선택 후 이동 유형 `561` 입력.
    - 자재(TEST_OIL), 플랜트, 저장위치, 수량(100,000L) 입력 후 Post.
- 재고 보충 확인 후 `VL02N`에서 PGI 재수행 시 정상 완료됨.

## 참고 자료
- T-Code: MIGO, MMBE(재고 조회)
