# Issues

프로젝트 진행 중 발생한 문제와 해결 과정을 기록하는 폴더입니다.

개발 과정 또는 설계 과정에서 발생한 오류, 이슈, 해결 방법을 정리합니다.

## 기록 내용

각 이슈 문서에는 다음 내용을 기록합니다.

- 발생 상황
- 원인 분석
- 해결 방법
- 참고 자료

## Purpose

- 동일한 문제 재발 방지
- 문제 해결 과정 기록
- 프로젝트 기술 아카이브 구축
