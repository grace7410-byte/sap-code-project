## [Issue #1] HTTP 외부 데이터 연동 시 XLS 파일 바이너리 변환 불능 결함 (FI) <a id="issue-1"></a>

### 1) 발생 현상
- 글로벌 유가 데이터 수집을 위해 제공된 외부 다운로드 인터페이스 링크로부터 HTTP 바이너리 스트림 형태의 XLS 확장자 파일을 수신하였으나, ABAP 프로그램 단에서 해당 원천 파일 바이너리를 텍스트 기반 문자열 데이터로 원활하게 변환·디코딩하지 못하여 인터페이스 연동이 전면 중단되는 결함이 발생하였다.

### 2) 해결 방안 및 조치
- 인코딩 변환 호환성 리스크가 있는 기존 XLS 원천 파일 포맷 대신, 경량화된 표준 텍스트 통신 규격인 CSV 파일 포맷 형식의 전용 다운로드 데이터 공급 링크로 엔드포인트를 스위칭 및 대체 지정하였다. 이를 통해 수신 레이어에서 별도의 복잡한 바이너리 변환 레이징 필터 없이 곧바로 가독성 높은 순수 문자열(String) 데이터셋으로 완벽하게 파싱 변환하여 내부 데이터 정합성 왜곡 문제를 완벽히 해결하였다.

## [Issue #2] 환율 마스터 테이블 내부 인코딩 형식 불일치로 인한 데이터 조회 불능 결함 (CO) <a id="issue-2"></a>

### 1) 발생 현상
- 원가 연산을 위해 시스템 백그라운드 단에서 실시간 환율 마스터 테이블 데이터를 리드(`READ`)해 오는 과정에서, 특정 데이터 적재 일자의 환율 명세 레코드가 무작위로 누락되거나 정상적으로 조회되지 않는 오류가 발생하였다. 원인 분석 결과, 환율 유형 필드(`KURST`) 내에 적재된 기본값 'M' 문자열 레코드의 철자는 동일했으나 데이터베이스 내부 인코딩 형식의 미세한 상이 문제로 인해 쿼리 조건절 매칭에 실패했던 것으로 판명되었다.

### 2) 해결 방안 및 조치
- 대상 마스터 테이블 내의 모든 환율 데이터 스키마 구조가 전부 'M'(표준 외환 매입 환율) 유형으로 일관되게 적재 및 강제 관리되고 있음을 데이터 정밀 검증을 통해 확인하였다. 이에 따라 불필요한 인코딩 매칭 캐시 충돌을 원천 방지하기 위하여, ABAP 프로그램 소스 코드 내 오픈 SQL 구문의 조회 조건절(Where Clause)에서 `KURST = 'M'` 필드 필터 조건을 명시적으로 삭제 및 제외 조치함으로써, 대상 일자의 환율 데이터셋이 왜곡 없이 완벽하게 서칭 및 컴포일되도록 트러블슈팅을 완료하였다.

## [Issue #3] 서비스 PO 아이템 총금액 오매핑 (MM) <a id="issue-3"></a>
 
### 1) 발생 현상
- 서비스 PO 아이템별 오더 총금액 계산 로직 구현 중, 실제 금액 데이터가 존재하는 특정 항목(예: 20번)이 아닌 금액이 없는 항목(10번)에 총금액이 잘못 저장되는 데이터 정합성 오류 발생  
  
### 2) 해결 방안 및 조치
- 더블 클릭 이벤트 핸들러 내에 방어 로직 추가: 원화 금액(DMBTR)이나 단가(NETPR)가 없는 무효 항목은 연산에서 제외(CONTINUE)하고, 정확한 라인 항목 번호(EBELP) 기준 고유 키값으로만 DB를 업데이트(UPDATE)하도록 개선

## [Issue #4] 부피측정 테이블 필드/도메인 수정 후 액티브 오류·경고 발생 (MM) <a id="issue-4"></a>
 
### 1) 발생 현상
- 부피측정 테이블 필드 및 도메인 수정 후 액티브 시 오류 1건, 경고 1건 발생  

### 2) 해결 방안 및 조치
- (오류) 해당 필드가 사용 중이던 데이터 요소(ZDVB1MM0001)에서 필드를 삭제 후 액티브화, 이후 다시 데이터 요소에 필드를 추가하여 해결
- (경고) 부피 보정 계수 도메인 타입을 DEC(5,2)에서 DEC(7,4)로 확장하는 과정에서 내부 길이는 늘어났으나 화면 출력 길이가 기존 길이(6)로 고정되어 발생 → output length를 8로 수정하여 해결

## [Issue #5] 마스터 데이터 음수(영하) 온도값 입력 시 SE16N 데이터 누락 (MM) <a id="issue-5"></a>
 
### 1) 발생 현상
- 마스터 데이터 중 영하 온도(예: -5도 ~ -0.1도) 입력 시, 테이블 키 필드에서 음수 부호(-)를 인식하지 못해 데이터 누락 리스크 발생. 온도 도메인 속성에 음수 허용 옵션([Sign])을 활성화했음에도 SE16N에서는 여전히 데이터 추가 불가

### 2) 해결 방안 및 조치
- SE16N 대신 전용 유지보수 뷰(ZMVB1MM0001)를 신규 생성하여 이를 통해 데이터를 일괄 입력하는 방식으로 우회 처리

## [Issue #6] 유지보수 뷰 드롭다운 강제 호출로 인한 데이터 길이 초과 오류 (MM) <a id="issue-6"></a>
 
### 1) 발생 현상
- 유지보수 뷰를 통해 데이터를 입력할 때, 온도 단위(ZUNIT)와 기준 온도(ZSTD) 필드가 도메인의 Fixed Value 설명글(예: '섭씨온도', 'BB6 환산기준')을 드롭다운 Listbox로 강제 호출하면서 데이터 길이 초과 및 복사·붙여넣기 오류 발생

### 2) 해결 방안 및 조치
- 유지보수 뷰의 Screen Painter(SE51) 화면으로 진입해 해당 필드들의 Dropdown 속성 해제. 기준온도 필드는 DEC 타입이라 Listbox 선택여부 옵션이 뜨지 않아 잠시 CHAR로 가변 변경하여 속성을 제거한 뒤, 다시 딕셔너리에 연결하여 해결

## [Issue #8] 전표유형 필터링 시 빈 값 데이터 유실 (FI) <a id="issue-8"></a>
 
### 1) 발생 현상
- 동적 상태 버튼 구현 과정에서 전표유형이 DR, DZ이고 빈 값인 데이터 중 DZ만 제거하려는 목적으로 WHERE 조건(DR이거나 빈 값일 때만, 또는 DZ가 아닐 때)을 적용했으나, 그럴 때마다 빈 값 데이터까지 함께 사라지는 현상 발생

### 2) 해결 방안 및 조치
- WHERE 조건 대신 참조문서번호키 필드와 송장청구문서번호 필드로 정렬한 뒤, 해당 정보가 담긴 내부 테이블 변수에서 전표유형이 DZ인 항목만 DELETE 하는 방식으로 변경하여 해결

## [Issue #11] 메시지 처리 함수 내 컨트롤러 컨텍스트(this) 유실 (SD) <a id="issue-11"></a>
 
### 1) 발생 현상
- 주문 확인 메시지 처리 함수 내에서 컨트롤러 this를 찾을 수 없는 현상 발생

### 2) 해결 방안 및 조치
- 메시지 박스가 열리고 닫히는 콜백은 자체 컨트롤러가 아닌 UI5 MessageBox가 호출하는 구조라 내부적으로 this가 컨트롤러를 가리키지 못하는 것이 원인. 화살표 함수(Arrow Function)를 사용해 컨트롤러를 this로 유지하도록 수정
