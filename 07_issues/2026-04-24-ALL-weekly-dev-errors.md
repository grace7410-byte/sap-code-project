## [Issue #1] TYPE 선언 시 LVC_T_STYLE 추가 후 VALUE #() 사용 시 런타임 덤프 오류 (MM) <a id="issue-1"></a>

### 1) 발생 현상
- TYPE 선언 시 LVC_T_STYLE 을 추가하고 이후 VALUE #()을 사용하고자 하면 DUMP 에러가 뜨는 현상 발생.

### 2) 해결 방안 및 조치
- VALUE # 대신 APPEND LINES OF 를 사용하여 데이터를 추가하는 방식으로 해결 조치 완료.

## [Issue #2] 실시간 테이블 자동 동기화 구현 불가에 따른 성능 제어 오류 (CO) <a id="issue-2"></a>

### 1) 발생 현상
- 실시간 업데이트의 경우 프로그램에 접속하여 REFRESH 를 누르지 않아도 자동으로 테이블에 업데이트되도록 구상하려 하였으나, 시간적 문제가 발생하는 현상 발생.

### 2) 해결 방안 및 조치
- 제한된 시간으로 안정성 있게 구현하기엔 무리가 있을 거라 판단해, 프로그램 내부 최초 진입 시점과 REFRESH 버튼을 눌렀을 경우에 데이터가 추가 및 업데이트가 되는 방식을 채택하여 해결 조치 완료.

## [Issue #3] 자재 코드 입력 시 이벤트 충돌로 인한 무한 루프 및 행 생성 오류 (MM) <a id="issue-3"></a>

### 1) 발생 현상
- 자재 코드 입력 시 연관 필드(단위, 단가 등)를 자동 채우는 과정에서 리프레시와 데이터 변경 이벤트가 충돌하여 '무한 루프' 및 '행 생성 오류' 현상이 발생함.

### 2) 해결 방안 및 조치
- HANDLE_DATA_CHANGED 이벤트 내에서 전체 리프레시를 수행하는 대신, 변경된 특정 셀만 정밀 조치하여 값을 업데이트하도록 로직을 수정함. 불필요한 전체 화면 갱신을 생략함으로써 무한 루프를 제어하고 WTI 필드 잔상 문제까지 연쇄적으로 조치 완료함.

## [Issue #4] BACK 버튼 이벤트 처리 시 서브스크린 재실행 및 화면 잠김 오류 (MM) <a id="issue-4"></a>

### 1) 발생 현상
- 200번 화면(최종: 100번 Screen으로 변경)에서 BACK 버튼을 클릭하여 복귀하려 할 때, 100번 화면(최종: Selection-screen으로 변경)의 자동 점프 로직이 원치 않게 재실행되면서 화면이 완전히 갇히는 무한 루프 현상이 발생함.

### 2) 해결 방안 및 조치
- 전역 사용자 복귀 플래그 필드(`gv_back`)를 프로그램에 새로 도입함. 사용자가 의도적으로 BACK을 눌러 화면을 빠져나갈 때 플래그를 설정하고, 의도적인 복귀 시점에는 이전 파라미터 체크 및 점프 로직을 타지 않도록 우회 제어하여 프로세스를 정상화함.

## [Issue #5] ALV 화면 조회 버튼 클릭 시 PAI 이후 스크린 종료 현상 (MM) <a id="issue-5"></a>

### 1) 발생 현상
- 200번 화면(최종: 100번 Screen으로 변경)에서 조회 버튼을 누른 후, 인터랙션 데이터는 정상 조회되나 현재 화면 레이아웃이 유지되지 않고 프로그램 세션이 그대로 종료되는 현상이 발생함.

### 2) 해결 방안 및 조치
- 해당 호출 스크린의 `Next Dynpro` 속성이 누락되었거나 제어가 잘못되어 발생한 오류로 파악되어, Next Dynpro 값을 현재 화면 번호(200번)로 강제 지정함. 이를 통해 PAI(Process After Input) 로직이 수행 완료된 이후에도 조회된 데이터 테이블이 유지된 채 화면 뷰가 지속되도록 구조 수정 완료함.

## [Issue #6] CDS View 내 CASE 구문 초기값 반환 오류 및 Open SQL 조회 불가 현상 (PP) <a id="issue-6"></a>

### 1) 발생 현상
- `ZCDS_B1_PP_0008` View 구축 중 특정 조건 외의 데이터에 대해 CASE-ELSE 문을 사용하여 0 값으로 지정하였으나, ABAP 프로그램에서 쿼리를 통해 해당 뷰를 호출할 때 0으로 채워진 레코드들이 누락되거나 정상적으로 조회되지 않는 현상이 발생함.

### 2) 해결 방안 및 조치
- 데이터베이스의 Null 값 연산 구조로 인해 데이터 누락이 발생한 것으로 확인되어, CDS View 소스 내에 `COALESCE` 함수를 명시적으로 도입함. 이를 통해 데이터가 존재하지 않는 Null 스페이스 필드에 대해 강제적으로 숫자 0을 치환하여 반환하도록 뷰 로직을 수정함으로써 Open SQL 상에서도 레코드가 정상 누적 및 감지되도록 해결함.

## [Issue #7] 재고 데이터 조회 시 정유 설비-저장 창고 특정에 따른 하드코딩 오류 (PP) <a id="issue-7"></a>

### 1) 발생 현상
- 자재 요구량 및 재고 연동 프로그램을 설계할 때, 고정된 생산 설비와 연계된 저장 창고(Storage Location)의 물리적 매핑 데이터를 특정하는 공통 기준이 부족하여 소스코드 내에 창고 코드를 직접 하드코딩해야 하는 성능 및 유지보수 결함 리스크가 발생함.

### 2) 해결 방안 및 조치
- 소스코드 내 리터럴 값 매핑을 지양하기 위해 관련 공정 모듈 담당자들과 기술 협의를 진행함. 물리적 위치 데이터를 마스터 수준에서 제어할 수 있도록 테이블 구조 변경 사양을 도출하였으며, 설비 정보 테이블에 창고 코드를 직접 연결하여 동적으로 특정할 수 있는 연관 필드를 추가 설계하는 방식으로 근본적인 해결 조치를 완료함.

## [Issue #8] 필드 카탈로그 빌드 시 파라미터 개수 불일치 구문 오류 (FI) <a id="issue-8"></a>

### 1) 발생 현상
- 전표 상세 내역을 출력하기 위한 ALV 필드 카탈로그(Field Catalog) 설정 과정에서 파라미터 설정 속성값들이 명세와 충돌하며, 지정된 설정치보다 더 많은 파라미터 인자가 필요하다는 예외 및 빌드 에러가 발생하여 프로그램 활성화가 제한됨.

### 2) 해결 방안 및 조치
- 필드 카탈로그 매크로 및 internal table 바인딩 구문 내부를 정밀 분석한 결과, 각 파라미터를 인덱싱하고 구분해 주는 끝자리 구문 기호인 콤마(`,`)의 누락 및 오타가 원인으로 파악됨. 구문 컴파일러 규칙에 맞게 모든 연동 구문의 콤마 마감 처리를 전수 수정 및 보정하여 구문 에러를 정상 조치함.

## [Issue #9] ALV 더블클릭 이벤트 후 스크린 필드 데이터 실시간 반영 불가 현상 (FI) <a id="issue-9"></a>

### 1) 발생 현상
- 사용자가 우측 Reference ALV의 특정 행을 더블클릭했을 때 내부 인터널 테이블 데이터는 정상 추출되나, 좌측 메인 스크린 Dynpro 화면 상의 Input 영역 필드 텍스트 박스에 데이터가 즉시 바인딩 및 갱신되지 않아 화면 잔상이 유지되는 제어 결함이 발생함.

### 2) 해결 방안 및 조치
- ALV 그리드 컨트롤 객체의 이벤트가 완료된 후 Dynpro 화면 단으로 제어권이 즉각 이행되지 않는 현상을 해결하기 위해 시스템 클래스 공통 메서드인 `CL_GUI_CFW=>SET_NEW_OK_CODE` 구문을 도입함. 해당 로직을 통해 더블클릭 핸들러 내부에서 가상의 OK_CODE를 강제로 시스템 스택에 밀어 넣어 PAI(Process After Input) 및 PBO 프로세스를 강제 트리거링함으로써, 화면 스크린 인풋창에 데이터가 실시간 갱신·표시되도록 조치 완료함.

## [Issue #10] PBO 프로세스 내 필드 속성 및 버튼 텍스트 동제어 시 제어 시점 오류 (FI) <a id="issue-10"></a>

### 1) 발생 현상
- 화면 제어 시 Input 필드의 활성화/비활성화 처리와 동적 버튼 텍스트(Text) 변경 로직이 동시에 수행됨에 따라, 프로그램이 의도한 시점에 필드 활성 상태가 정상적으로 반영되지 않는 제어 타이밍 오류가 발생함.

### 2) 해결 방안 및 조치
- PBO(Process Before Output) 내부의 서로 다른 두 위치에서 분산 처리되던 필드 활성/비활성 제어 로직을 통합함. 하나의 제어 블록 내에서 명확한 조건별 분기처리 구조로 재구성함으로써 화면 출력 시점의 제어 정합성을 확보하고 오류를 해결함.

## [Issue #11] COLLECT 함수 사용에 따른 환율 필드 데이터 누적 합산 현상 (FI) <a id="issue-11"></a>

### 1) 발생 현상
- 내부 인터널 테이블 집계를 위해 COLLECT 함수를 사용하는 과정에서, 고유 키값에 따른 금액 정보뿐만 아니라 단순 참조 데이터인 환율(Rate) 필드 값까지 함께 누적 합산되어 출력 데이터가 왜곡되는 현상이 발생함.

### 2) 해결 방안 및 조치
- COLLECT 함수 적용 단계에서 환율 필드를 제외하고 데이터 집계를 수행하도록 수정함. ALV에 바인딩할 출력용 데이터 구성을 완료한 후, 인터널 테이블 LOOP 문을 순회하며 마스터 레코드의 정확한 환율 값을 1:1로 매핑·적용해 주는 구조로 변경하여 데이터 왜곡 오류를 조치함.

## [Issue #12] ALV 이벤트 내 숏덤프(E Type Message)로 인한 프로그램 비정상 종료 현상 (SD) <a id="issue-12"></a>

### 1) 발생 현상
- 헤더 ALV 행 클릭 시 서브 아이템 ALV 데이터를 동적 바인딩하는 로직에서, 내역이 존재하지 않는 헤더 행을 선택할 때 시스템 예외 처리를 위해 Message Type 'E'(Error)를 트리거함. 이로 인해 정상적인 아이템 데이터를 보유한 타 행을 클릭하는 시점에도 화면 전환 및 갱신이 이루어지지 않고 세션이 강제 종료(Shut down)되는 결함이 발생함.

### 2) 해결 방안 및 조치
- 대화형 스크린 프로세스 진행 중 시스템 멈춤 및 비정상 종료를 유발하는 하드 코딩 에러(`MESSAGE ... TYPE 'E'`)를 억제하도록 수정함. 대신 사용자 알림과 비즈니스 로직 유지를 동시에 만족할 수 있도록 상태바에 전송하는 `MESSAGE ... TYPE 'S' DISPLAY LIKE 'W'` 구조로 선언을 변경하여, 세션 파괴를 원천 방지하고 후속 그리드 인터랙션이 정상 작동하도록 조치함.

## [Issue #13] CL_GUI_TEXTEDIT 컨트롤의 SET_TABLE_AS_STREAM 메서드 데이터 반영 실패 오류 (SD) <a id="issue-13"></a>

### 1) 발생 현상
- `CL_GUI_TEXTEDIT` 클래스 컨트롤을 활용하여 화면상에 작업 이력 로그 박스를 구현하는 과정에서, 출력 타겟 인터널 테이블(`gt_text`)에 정상적으로 로깅 텍스트 데이터가 적재되어 있음에도 불구하고 `set_table_as_stream` 메서드가 스트림 데이터를 렌더링하지 못해 화면에 텍스트가 표시되지 않는 오작동 현상이 발생함.

### 2) 해결 방안 및 조치
- 데이터 오브젝트 선언부를 추적한 결과, 개별 라인 구조인 `gs_text`는 `CHAR255` 구조로 선언하고 적재 테이블인 `gt_text`는 `STANDARD TABLE OF STRING`으로 혼용 선언한 뒤 `APPEND` 처리를 수행한 것이 원인으로 판명됨. 두 데이터 오브젝트가 참조하는 기본 문자열 속성이 상이하여 컨테이너 스트림 전달 과정에서 데이터가 유실되었으므로, 구조 타입 선언부를 `STRING` 형식으로 완벽하게 일치시킨 후 재빌드하여 해당 텍스트 스트림 메서드가 정상 동작하도록 해결함.
