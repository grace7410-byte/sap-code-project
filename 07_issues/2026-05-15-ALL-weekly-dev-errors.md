목적: 전사 모듈(MM/SD/PP/FI/CO) 구현 과정에서 발생한 모든 기술적 오류, 시스템 버그 및 트러블슈팅 내역을 한 번에 통합 관리함.

## [Issue #1] 동적 테이블 변수 선언 시 필드 심볼 TYPE ANY 지정에 따른 시스템 런타임 덤프 결함 (MM) <a id="issue-1"></a>

### 1) 발생 현상
- 런타임 환경에서 동적 테이블(Dynamic Table) 아키텍처 구성을 위해 변수를 선언하는 과정에서, 참조 필드 심볼(Field Symbol)의 데이터 구조 타입을 `TYPE ANY`로 작성함에 따라, 프로그램이 테이블 인스턴스를 정상 수용하지 못하고 시스템 런타임 덤프(Short Dump) 예외가 발생하는 결함이 발생함.

### 2) 해결 방안 및 조치
- 동적 객체의 참조 인터페이스 구문을 단일 오브젝트 타입이 아닌 `TYPE STANDARD TABLE` 구조로 명시적 교정 선언함. 이를 통해 동적으로 생성되는 테이블 내부 데이터셋의 포인터를 필드 심볼(F.S)이 TABLE 타입 인터페이스로 정합성 있게 매핑하고 제어할 수 있도록 처리하여 덤프 오류를 해결함.

## [Issue #2] KRW 단가 필드의 ALV 출력 시 소수점 강제 표기 및 외화 통화 마스터 맵핑 결함 (CO) <a id="issue-2"></a>

### 1) 발생 현상
- 통화 속성 상 소수점 자리가 존재하지 않는 원화(KRW) 기반의 원유 투입 상세 단가 데이터를 ALV 그리드로 출력할 때, 카탈로그 버퍼 오류로 인해 모든 금액 필드 후미에 '.00' 소수점이 강제로 렌더링되어 데이터 가독성을 저해하는 현상이 발생함. 또한 USD 등 외화 공정비 필드와의 통화 코드 참조 불일치 결함이 동시 발생함.

### 2) 해결 방안 및 조치
- 원화(KRW) 단가 필드의 카탈로그 구조에 소수점 표현 제어 속성인 `DECIMALS_O = 0`을 동적으로 하드코딩 반영하여 소수점 노출을 원천 필터링 조치함. 아울러 다중 통화 혼재 문제를 해결하기 위해, USD 공정비 도메인 영역에 필드 필터 속성인 `REF_TABLE`, `REF_FIELD`, `CFIELD` 마스터 데이터를 명시적으로 매핑 및 바인딩하여 통화 키 세션별로 소수점 출력을 완벽히 격리 제어함.

## [Issue #3] ALV 그리드 필드 카탈로그 강조색(Color Cell) 유실 및 편집 모드(Ready for Input) 속성 충돌 결함 (MM) <a id="issue-3"></a>

### 1) 발생 현상
- 100 번 스크린 하단의 대시보드 ALV 인스턴스 레이아웃 구조체(`GS_LAYO_POHD`) 및 필드 카탈로그(`GT_FCAT_POHD`)에 특정 키 필드 강조색(Color 코드 `C110`)을 명시적으로 매핑하였으나, 런타임 출력 시 해당 인덱스 셀의 강조 렌더링이 소멸하고 기본 스타일 세션으로 강제 오버라이딩되는 오류 직면. display_alv 구문 직전까지 버퍼 인터널 테이블 데이터가 완벽하게 상속되고 있음에도 뷰 레이어에서 색상이 생략되는 모순 발생.

### 2) 해결 방안 및 조치
- 정밀 런타임 디버깅을 실행한 결과, 해당 인터페이스 그리드는 '조회 전용' 인스턴스로 설계되어 카탈로그 내부의 `EDIT` 속성이 차단(SPACE)되어 있었으나, 컨트롤러 활성화 세션에서 `set_ready_for_input = 1` 메서드가 중복 호출되면서 SAP 표준 컨테이너 내부 덤프 방지 락(Lock)과 속성 간의 충돌을 유발시켰음을 검증함. 조회 전용 뷰의 정합성을 보장하기 위해 충돌의 원인이 된 `set_ready_for_input` 강제 주입 구문을 주석(Comment) 처리하여 제거함으로써 ALV 셀 강조색이 정상 표출되도록 최종 교정 조치함.

## [Issue #4] 계층형 트리 노드 탐색 로직의 소스 코드 복잡성 결함 (PP) 

### 1) 발생 현상
MRP 프로그램에서 목적 값을 찾아 트리 노드를 탐색하고 확장하는 과정에서, 탐색 코드가 필요 이상으로 복잡하게 구성되어 가독성이 떨어지고 유지보수가 어려워지는 결함이 발생함.

### 2) 해결 방안 및 조치
내부 테이블(Internal Table)에 일자와 트리 노드 객체를 함께 관리하는 전용 테이블을 구축함. 이를 인덱스 테이블처럼 활용하여 불필요한 탐색 레이어를 줄이고 노드를 즉각 제어할 수 있도록 단순화함.

## [Issue #5] 도메인 및 DB 테이블 변경 사항의 세션 버퍼 동기화 지연 결함 (PP) 

### 1) 발생 현상
자재-공정 연결 프로그램 개발 중, 도메인(Domain) 속성을 변경하고 연관 DB 테이블을 업데이트했음에도 불구하고 시스템 런타임에서 이전 타입 스펙을 지속적으로 참조하여 데이터 생성이 불가능한 타입 오류가 발생함.

### 2) 해결 방안 및 조치
SAP 커맨드 창에 버퍼 강제 초기화 명령어인 /$sync를 실행하여, 변경된 데이터 딕셔너리 스펙이 시스템 세션 및 애플리케이션 버퍼에 즉각 동기화되어 정상 반영되도록 조치함.

## [Issue #6] COLLECT 구문을 활용한 데이터 집계 시 시스템 덤프(DUMP) 결함 (PP) 

### 1) 발생 현상
내부 테이블 내부에서 데이터를 요약 및 그룹화하기 위해 COLLECT 구문을 사용하는 과정에서, 테이블 구조체의 키 지정 오류로 인해 정합성이 깨지며 시스템 쇼트 덤프(DUMP)가 발생하는 결함이 발생함.

### 2) 해결 방안 및 조치
TYPES 구문으로 요약 대상 내부 테이블의 타입을 정의할 때, 정렬 및 집계 기준 키 필드가 명확히 구분되도록 NON-UNIQUE KEY 지정을 추가 선언하여 구조적 충돌을 해결함.

## [Issue #7] 단일 화면 내 다중 그래프 차트 컨트롤 렌더링 무력화 결함 (PP) 

### 1) 발생 현상
생산계획 프로그램의 대시보드 화면상에 복수의 설비 가동률 변동 그래프를 배치하여 그릴 때, 그래픽 엔진 인스턴스의 컨테이너 공유 충돌로 인해 마지막 그래프를 제외한 나머지 이전 그래프들이 화면에 렌더링되지 않는 현상이 발생함.

### 2) 해결 방안 및 조치
하나의 그래픽 프록시가 화면을 덮어쓰지 않도록 각 차트 출력 영역마다 독립된 그래픽 엔진 객체를 개별 변수로 각각 분리 선언하고 호출함으로써 렌더링 충돌 문제를 완벽히 해결함.

## [Issue #8] Fiori Gateway 인터페이스 통화 금액 필드의 소수점(.00) 강제 렌더링 결함 (FI) <a id="issue-8"></a>

### 1) 발생 현상
- fiori ar 반제 프로그램 구축 및 OData 서비스 데이터 바인딩 과정 중, 백엔드 데이터베이스로부터 통화 금액 필드 데이터를 인터페이스 테이블로 스트리밍할 때, 화면 레이어단에서 원화 기반 데이터임에도 불구하고 후미에 소수점 `.00`이 무조건 강제로 생성되어 표출되는 버그가 발생함. 이는 전사 회계 리포트의 가독성을 심각하게 해치고 데이터 불일치 오해를 유발할 수 있는 결함으로 확인됨.

### 2) 해결 방안 및 조치
- SAP 내부 금액 데이터 보관 명세 규격과 Fiori UI 컴포넌트 간의 데이터 출력 포맷을 정합성 있게 매핑하기 위해, 데이터를 게이트웨이 세션으로 서빙하는 백엔드 API 파이프라인 최종 출력 단에 통화 데이터 변환 표준 펑션 모듈인 `CURRENCY_AMOUNT_SAP_TO_DISPLAY`를 추가 구현함. 이를 통해 내부 버퍼 스펙의 소수점 자릿수를 강제 변환 및 억제 필터링 처리하여 가독성이 보장된 정상 정수 금액 구조로 정상 출력되도록 조치함.

## [Issue #9] Fiori 데이터 바인딩 시점 오류로 인한 마스터-디테일 테이블 데이터 자동 출력 결함 (FI) <a id="issue-9"></a>

### 1) 발생 현상
- fiori에서 거래목록 테이블의 데이터가 공급업체 미 선택시에도 바로 출력되는 현상 발생. 상단 마스터 공급업체가 지정되지 않은 런타임 초기 세션 환경임에도 하단 리스트가 차단되지 않고 그대로 렌더링되는 결함 직면.

## [Issue #10] ABAP ALV 금액 필드 원화(KRW) 소수점 노출 결함 (SD) <a id="issue-10"></a>

### 1) 발생 현상
- ABAP ALV 화면에서 금액 데이터 필드의 통화 속성이 명확히 KRW(원화)로 바인딩되어 있음에도 불구하고, 내부 버퍼 오류로 인해 출력 화면상에서 금액 데이터 후미에 `.00` 소수점이 계속 강제로 붙어서 가시성이 심각하게 훼손되는 현상이 발생하였다.

### 2) 해결 방안 및 조치
- 인터페이스 테이블에서 데이터를 화면으로 스트리밍하기 직전, 내부 원화 포맷 제어용 표준 함수인 `BAPI_CURRENCY_CONV_TO_INTERNAL`을 소스 코드 단에서 호출하도록 구조를 수정하였다. 이를 통해 시스템 내부의 불필요한 소수점 명세를 강제로 제거하여 원화 규격에 맞는 깔끔한 정수 형태로 출력되도록 해결하였다.

## [Issue #11] PAI 로직 내 엔터 이벤트 발생 인풋 필드 식별 불가 결함 (SD) <a id="issue-11"></a>

### 1) 발생 현상
- 인풋 필드 영역에 사용자가 수치를 입력한 후 엔터(Enter) 키를 누르면 화면의 PAI(Process After Input) 로직을 정상적으로 타도록 구성하였으나, 런타임 환경에서 시스템이 현재 이벤트를 발생시킨 인풋창이 유효시작일 필드인지 혹은 마진율 퍼센트 입력 필드인지 고유의 필드 ID를 인식 및 구분하지 못하는 결함이 식별되었다.

### 2) 해결 방안 및 조치
- PAI 트랜잭션 초입 영역에 SAP GUI 스크린 제어 구문인 `GET CURSOR` 명령어를 명시적으로 구현하였다. 런타임 시점에 사용자의 커서가 위치한 물리 필드의 고유 테크니컬 네임 값을 실시간으로 변수에 캐치 및 인터셉트하도록 소스를 수정하여, PAI 세션 내부에서 각 필드별 프로세스를 정밀하게 분기 및 구분하도록 처리하였다.

## [Issue #12] Fiori StepInput 수량 하향 조정 시 상단 합계 금액 미차감 결함 (SD) <a id="issue-12"></a>

### 1) 발생 현상
- Fiori UI 애플리케이션 화면에서 유저가 a제품 수량 1개와 b제품 수량 1개를 각각 마우스로 가변 선택하였을 때에는 상단 대시보드의 통합 합계 금액 필드에 정상적으로 합산 연산되어 렌더링되었으나, b제품의 수량을 1개에서 0개로 하향 조정하여 변경하는 예외적인 케이스가 발생하였을 때에는 상단 합계 가격 데이터가 차감되지 않고 기존 가격을 그대로 유지하고 있는 데이터 왜곡 오류 현상이 발생하였다.

### 2) 해결 방안 및 조치
- Fiori 뷰 레이어 단에 인라인 형태로 산만하게 분산되어 있던 가격 계산 수식 로직들을 자바스크립트 `controller.js` 단의 독립적인 커스텀 함수(Function) 구조로 전면 격리 및 추출하였다. 이후 UI의 StepInput 컴포넌트 상에서 수량 변경 이벤트(`change`)가 감지되어 트리거될 때마다, 전체 타깃 제품 6개에 대한 실시간 개별 금액 계산을 백그라운드에서 매번 전수 재실행한 뒤 이를 마스터 변수에 통째로 재합산하여 덮어쓰는 동적 루프 방식으로 아키텍처를 개편하여 연산 결함을 완벽하게 해결하였다.
