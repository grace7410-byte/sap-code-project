# [Anvil Integrated Issue Log] 2026-04-30 전사 통합 개발 이슈 모음집

목적: 전사 모듈(MM/SD/PP/FI/CO) 구현 과정에서 발생한 모든 기술적 오류, 시스템 버그 및 트러블슈팅 내역을 한 번에 통합 관리함.
1) 발생현상, 2) 해결 방안 및 조치 순으로 기재.

## [Issue #1] 다중 서브스크린(Subscreen) 간 동적 데이터 전달 및 PAI 호출 시 갱신 누락 현상 (MM) <a id="issue-1"></a>

### 1) 발생 현상
- 단일 메인 화면 레이아웃 구조 내에서 총 5개의 다중 서브스크린 영역(Subscreen Area)을 동적으로 제어하며 입력값과 입력창을 독립 분리 관리하도록 설계함.
- 특정 서브스크린 영역에서 이벤트가 트리거되어 타 서브스크린의 컨텍스트 필드 값을 변경 및 업데이트하도록 연동하였으나, 스크린 제어권이 PAI(Process After Input) 인터랙션 사이클로 진입하는 과정에서 변경된 서브스크린 인스턴스가 재호출될 때 변경 정보가 인터페이스 버퍼에 반영되지 못하고 기존의 유실된 초기 상태값으로 덮어써 지는 화면 갱신 누락 결함이 발생함.

### 2) 해결 방안 및 조치
- 타 서브스크린의 런타임 데이터를 직접 실시간으로 제어·변경하는 방식의 강한 결합도를 지양하고, 시스템 아키텍처 구조의 독립성을 확보하기 위해 전역 제어용 플래그성 객체인 '체크 변수(Check Variable)' 로직을 설계 도입함.
- 값의 변경이 일어나는 시점에 타 서브스크린 화면을 강제 직접 갱신하는 대신 데이터 변경 요청 정보를 담은 체크 변수만을 우선 마킹(X) 처리함. 이후, 타겟 서브스크린에 사용자가 세션 진입 및 접속하는 시점의 PBO(Process Before Output) 루프 내에서 해당 체크 변수의 마킹 상태를 조건 검증하여 자체적으로 화면을 안전하게 갱신·바인딩하도록 분기 로직을 전면 재구성함으로써 제어 정합성 오류를 조치 완료함.

## [Issue #2] PBO 단계 내 차트 컨트롤러 인스턴스 미생성 상태의 메서드 호출 덤프 오류 (MM) <a id="issue-2"></a>

### 1) 발생 현상
- 화면 PBO(Process Before Output) 로직 단계에서, 차트 컨트롤러 객체가 완벽하게 인스턴스화(Instantiation)되어 메모리에 상주하기 전에 데이터 렌더링 관련 호출 메서드가 선행 실행되면서 참조 무효화로 인한 시스템 예외 및 런타임 숏덤프(Dump)가 발생하는 현상이 발생함.

### 2) 해결 방안 및 조치
- 객체 지향 방어 코드를 적용하여, 메서드 호출 바인딩 단 직전에 글로벌 객체 변수의 유효성을 검증하는 `IF go_chartall IS BOUND` 제어 구문을 명시적으로 설계 추가함. 객체가 확실히 생성 완료된 시점에만 데이터 렌더링 프로세스가 트리거되도록 예외 처리 구조를 개선 완료함.

## [Issue #3] 데이터 타입 불일치 및 텍스트 비교 로직 기인 차트 데이터 집계 누실 오류 (MM) <a id="issue-3"></a>

### 1) 발생 현상
- 수율 분석 차트 컴포넌트 구현 프로세스 중, 내부 최적화 테이블의 원유 코드 파라미터와 자재 마스터 테이블의 자재 코드(MATNR) 간 데이터 정합성이 일치하지 않거나, 부정확한 단순 텍스트 필드 매칭 비교 로직을 수행함에 따라 데이터 바인딩 연산이 오작동하여 차트 데이터 스택이 '0'으로 집계 및 렌더링되는 오류가 발생함.

### 2) 해결 방안 및 조치
- 모호한 텍스트 수평 비교 방식을 전면 배제하고, 마스터 필드의 핵심 키값인 자재 코드(MATNR) 및 원유 코드를 기준으로 완벽한 1:1 매칭 구조를 수립함. 또한 공급업체-원재료-수율 조건 테이블이 유기적인 선형 연동을 이룰 수 있도록 내부 `READ TABLE` 제어 조건 구문을 정밀 보정하여 데이터 집계 누실 현상을 조치 완료함.

## [Issue #4] 데이터 유실 테이블 조인(JOIN) 처리에 따른 오더 아이템 레코드 누락 현상 (MM) <a id="issue-4"></a>

### 1) 발생 현상
- 물류 및 오더 데이터 추출을 위한 데이터베이스 쿼리 수행 시, 측정 이력 데이터베이스 테이블인 ZTB1MM0020에 연관 레코드가 존재하지 않는 경우 INNER JOIN 또는 잘못된 조건 결합으로 인해 상위 구매오더 아이템 레코드 데이터 세트 전체가 결과 집합에서 강제 제외 및 누락되는 현상이 발생함.

### 2) 해결 방안 및 조치
- 단순 DB 뷰 또는 하드한 조인 쿼리에 의존하지 않고, 데이터 버퍼를 순회하는 내부 인터널 테이블 `LOOP` 구문을 설계함. 루프 내부에서 프로세스(`process`) 영역이 공백 상태인 행을 식별하면 헤더 버퍼 구조인 `gt_head`를 대상으로 `READ TABLE` 역참조를 직접 구동하여, 누락된 오더 마스터 정보를 런타임에 강제 복원 및 매핑함으로써 데이터 유실 결함을 원천 차단 조치 완료함.

## [Issue #5] 필드 카탈로그 구성 파라미터 매핑 불일치 및 구문 구분자 누락 오류 (FI) <a id="issue-5"></a>

### 1) 발생 현상
- 전표 화면에 ALV 그리드를 렌더링하기 위해 필드 카탈로그(Field Catalog) 매핑 설정을 빌드하던 중, 사전에 인스턴스 구조에 선언된 파라미터 제약 조건보다 초과된 파라미터가 바인딩되거나 런타임 데이터 구조 불일치 현상이 감지되어 시스템 예외 오류가 발생함.

### 2) 해결 방안 및 조치
- 데이터 매핑 구문을 패키지 단위로 전수 검증하여 비정상적인 구조적 결합을 해제함. 특히 펑션/메서드 호출부의 개별 파라미터 라인 끝단에 ABAP 필수 구분자인 콤마(,)가 누락되거나 잘못 위장되어 컴파일러가 매크로 구문으로 오인하던 현상을 식별하고, 전체 필드 카탈로그 구조 서식을 가다듬어 싱크 정합성을 확보 완료함.

## [Issue #6] ALV 더블클릭 이벤트 인스턴스 데이터의 메인 스크린 입력창 바인딩 불능 결함 (FI) <a id="issue-5"></a>

### 1) 발생 현상
- 전표 REF Table ALV 그리드 영역에서 사용자 더블클릭(`DOUBLE_CLICK`) 이벤트가 정상적으로 트리거되어 내부 인터널 테이블 버퍼 데이터는 갱신되었으나, 런타임 상에서 해당 행 자재 및 전표 정보가 메인 다이얼로그 스크린의 입력 텍스트 필드(Input Field) 오브젝트 화면으로 즉각 리프레시되어 반영되지 않는 화면 동기화 유실 결함이 발생함.

### 2) 해결 방안 및 조치
- 이벤트 핸들러 메서드 내부 로직 최하단에 SAP 표준 GUI 프레임워크 동적 제어 함수인 `CL_GUI_CFW=>SET_NEW_OK_CODE` 메서드를 구현 및 명시적으로 호출함. 이를 통해 프로그램 제어 사이클이 PAI(Process After Input) 단계를 강제로 관통하여 타도록 아키텍처를 바이패스시킴으로써, 동적 스크린 전송 버퍼가 갱신되어 입력창 오브젝트에 데이터가 정상 출력되도록 조치 완료함.

## [Issue #7] 동적 서치헬프 내 라디오버튼 선택 값 인식 불능 결함 (FI) <a id="issue-7"></a>

### 1) 발생 현상
- 참조문서번호 조회 서치헬프(Search Help) 구동 시 사용자가 선택한 라디오버튼의 종류에 따라 참조 대상 마스터 테이블을 가변적으로 분기 매핑해야 하나, 런타임 프로세스에서 라디오 버튼의 현재 선택 flag 값을 프로그램 버퍼가 정확히 식별하지 못해 데이터 바인딩이 유실되는 현상이 발생함.

### 2) 해결 방안 및 조치
- 서치헬프 펑션 내부에서 메인 화면의 오브젝트 메모리 주소를 직접 참조할 수 있도록 필드 심볼(Field Symbol) 변수를 선언함. 실행 시점에 활성화된 라디오버튼 오브젝트의 값을 동적으로 포인팅하여 실시간 값을 다이렉트로 인식할 수 있도록 구문을 개선 완료함.

## [Issue #8] 서치헬프 내 기생성 참조 전표 중복 추출 제한 조치 결함 (FI) <a id="issue-8"></a>

### 1) 발생 현상
- 선적입고 및 송장 참조 데이터 조회 시, 이미 FI 전표 테이블에 전표 생성이 완료되어 처리가 끝난 참조문서번호까지 서치헬프 결과 리스트에 중복 노출되어 데이터 중복 적재 위험 및 사용자 혼선이 야기됨.

### 2) 해결 방안 및 조치
- 참조 대상 문서 추출 데이터 셀렉션 로직의 WHERE 조건 절 내부에 `NOT IN` 서브쿼리 구문을 도입함. 현재 운영 중인 FI 전표 헤더 테이블(Header Table)에 이미 존재하고 있는 참조문서번호 리스트를 조건에서 완전 제외(Filtering) 시킴으로써 중복 생성이 불가능한 순수 미처리 문서 번호만 추출되도록 무결성을 보장 조치함.

## [Issue #9] DB 데이터 변경 이벤트 발생 시 ALV 화면 REFRESH 동기화 유실 결함 (SD) <a id="issue-9"></a>

### 1) 발생 현상
- 출고 및 청구 트랜잭션이 완료되어 수동 또는 자동으로 데이터베이스(DB) 테이블 내 적재 데이터가 동적 변경되었으나, ALV 그리드 오브젝트의 `refresh_table_display` 메서드 호출 만으로는 변경된 최신 레코드가 스크린 화면에 즉각 반영되지 않고 이전 버퍼 데이터가 그대로 잔존하는 현상이 발생함.

### 2) 해결 방안 및 조치
- ALV 그리드 리프레시 펑션을 타기 전 단계에서, 소스 DB 테이블로부터 바인딩 대상 데이터를 역으로 재조회하는 `SELECT` 쿼리 세션을 명시적으로 재배치함. 최신화된 데이터셋을 내부 인터널 테이블에 강제로 수용(Fetch)시킨 후 그리드 인스턴스를 갱신함으로써, 데이터 정합성을 항시 유지하도록 프로세스를 보정 완료함.
