# SAP CODE Project
> **CODE Academy CL2 1기 최종 프로젝트 반 1등 (우수상 수상)**  
> 정유 산업 특화 프로세스 설계 및 MM/PP/SD/FI/CO 전사 통합 CBO 구축 프로젝트

## 📌 Overview
가상 정유기업 **C-Nergy**(원유 정제·수출 전문, No.1 Crude oil processing & export company)를 대상으로, SAP S/4HANA 기반 MM·PP·SD·FI·CO 전사 통합 시스템을 설계·개발한 프로젝트입니다.

- 정유 산업 특화 도메인 로직 구현 (15℃ 환산 표준 부피, 이송 중 자연 증발 손실 처리, MOPS 국제 제품가 연동, 연산품 원가 배분 등)
- ABAP 기반 CBO(Custom Business Object) 개발 및 Fiori UI 구현
- SAP RAP 모델 및 OData Service 노출을 통한 확장 개발 수행

## 🎯 Key Experience
- 구매(MM) → 생산(PP) → 판매(SD) → 재무/원가(FI/CO)로 이어지는 전사 End-to-End 프로세스 설계
- 물류 트랜잭션 발생 시 FI/CO 전표가 자동 연동되는 인터페이스 구현
- SAP RAP 기반 확장 개발(CBO) 및 Fiori Elements 화면 구현
