## Key Discussion
* **SD 모듈 일자별 MOPS 실가격 반영**: SD 모듈은 오피넷 사이트의 싱가포르 국제 제품가(MOPS) API를 연동하여 매일 변동되는 실제 시장 금액(100 USD 초과 시황)을 그대로 가져와 내부 판매 기본가로 설정하고, 여기에 계약별 알파 가격을 추가하는 정유 산업 특화 판가 로직을 확정함.
* **MOPS 제품가-내부 유종 자재 매핑 표준화**: 오피넷 공시 지표와 자재 마스터 간의 1:1 매핑 룰을 아래와 같이 세부 확정함.
  - 휘발유 95 ron -> 휘발유 / 휘발유 92 ron -> lpg / 등유 -> 항공유 / 경유(0.001) -> 경유 / 고유황중유 -> 아스팔트 / 나프타 -> 나프타
* **MM 모듈 원유 도입가 안정화 방침**: 기존에 오피넷에서 dubai, wti, brent/maya 등의 원유 가격을 동적으로 가져오려던 MM 쪽 로직은 현재 1 bbl당 100 USD가 넘는 극심한 고유가 시황 반영 시 CO 모듈의 내부 원가 마진이 왜곡되는 문제를 방지하기 위해, 동적 연동 대신 기존의 75~85 USD 선을 유지하는 방향으로 조율함.
* **MM-LE 데이터 아키텍처 정합성 리팩토링**: LE 모듈의 선적/실측별 아이템 단위 부분 운송 프로세스를 수용하기 위해 구매오더 헤더 테이블의 `POSTAT` 필드 삭제 결정. Index 03 팀원이 종속된 CDS View 구조를 점심시간 이후 수정하고 DB를 최종 리빌드 및 액티베이션 처리함.

## Decision
* **아이템 기반 헤더 상태 역산 알고리즘 도입**: 헤더 테이블 내 `POSTAT` 필드가 삭제됨에 따라, 화면 조회/수정/삭제 및 후속 입고/송장 검증 시점에 전체 아이템 상태를 오름차순 정렬(`SORT BY postat ASCENDING`)한 후, 가장 낮은 최하위 단계 값을 헤더 대표 상태값(`gv_postat`)으로 실시간 트래킹하여 도메인 텍스트와 바인딩 출력하도록 예외 로직 구축.
