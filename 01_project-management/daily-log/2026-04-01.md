# 2026-04-01

## Summary
설계의 핵심인 '데이터 시뮬레이션' 단계에 진입하여 SCM-FI 전표 연동성을 검증함. MM의 수입 프로세스 재정립과 PP의 원가 차이 분석을 위한 데이터 구조를 확립하며 FCM 모듈로의 데이터 전달 준비를 마침.

## Key Discussion
- **MM 수입/운송 프로세스**: 선적 입고(In-transit GR) 시점을 실측 부피 기반의 '확정 수량' 인정 시점으로 재정의하고, 플랜트 입고는 내부 로스 파악용으로 성격을 명확히 함.
- **PP-CO 생산 데이터 이원화**: 계획 수율 기반의 생산 오더와 실제 생산 실적 간의 차이를 분석하기 위해 자재 이동(Actual) 데이터를 직접 입력하는 이원화 로직 검토.
- **FI-CO 연동 전표 시뮬레이션**: 원유 투입(261)부터 반제품/완제품 입고(101)까지의 계정 결정(T030) 및 제조원가 배부 임시계정 상계 시나리오 분석.

## Decision
- **수입 프로세스 확립**: [선적 입고 → 송장 검증 → 대금 지급 → 플랜트 입고(내부 로스 정산)] 순으로 프로세스 정립.
- **데이터 기록 원칙**: 생산 오더는 예측치로 생성하되 실제 자재 이동 문서는 실측치로 생성하여 CO에서 차이(Variance) 분석이 가능한 구조 확보.

- 모듈별 분산된 테이블을 병합하여 통합 ERD 최종 정합성 체크.
