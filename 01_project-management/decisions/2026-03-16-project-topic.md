# Project Topic Decision

Date: 2026-03-16


## Company Name

**C-nergy**

Meaning

- Code
- Energy
- Synergy

정유 산업 특성을 반영하면서 팀 협업의 의미를 포함하는 이름으로 결정하였다.


## Decision

프로젝트 산업을 정유 산업(Refinery Industry)으로 최종 선정하였다.


## Reason

정유 산업은 다음과 같은 특징을 가진다.

- 연속 공정 기반 생산 구조
- 하나의 원유에서 여러 제품이 동시에 생산되는 연산품 구조
- 복잡한 원가 계산 구조

이러한 특성으로 인해

- SAP Standard 기능만으로 해결하기 어려운 산업 로직이 존재하며
- CBO 기반 확장 개발이 가능한 프로젝트 주제로 적합하다고 판단하였다.
