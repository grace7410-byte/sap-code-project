# 데이터 스케일 상향 및 UI/UX 표준 수립 Decision

Date: 2026-05-14

## Decision
**1. 전사 데이터 수량(Volume) 스케일 상향 및 동기화**
* SD(판매)의 현실적인 유종별 1회 주문 수량 가이드를 마스터 기준으로 삼고, 이에 맞추어 PP(생산) 오더량 및 MM(구매) 원유 도입량 데이터 스케일을 상향 정렬함.

**2. 전 모듈 공통 UI/UX 개발 표준 수립**
* 수정 불가 필드는 'Display Only'로 제한하고 수량/금액 필드는 '우측 정렬' 처리함. 금액 계산 시 원화(KRW) 소수점 오류 방지를 위해 소스코드 내 `*100 /100` 하드코딩을 금지하고 SAP 표준 통화키 매핑을 적용함.

## Reason
* **데이터 스케일 상향 이유**: 소액 시뮬레이션을 위해 축소했던 기존 수량이 Fiori UI 화면 및 정유 도메인 실제 물동량(탱크로리 분량 등)과 너무 동떨어져, 전사 통합 데이터 적재를 앞두고 데이터의 현실성과 정합성을 높이기 위함.
* **UI/UX 표준 수립 이유**: 사내강사 멘토링 지적 사항을 바탕으로 프로그램의 조회조건 통일성, 예외 처리, 사용자 편의성을 강화하여 전사 프로그램의 완성도를 높이기 위함.
