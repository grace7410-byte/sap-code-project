# 팀 프로그램 스펙서 — C-Nergy (7인 전체)

팀원 7명이 개발한 전체 프로그램(MM·PP·SD·FI·CO, 총 58개)을 담당자별로 정리한 문서입니다.

---

## 엄영욱 (PP) — 9개 프로그램

### 1. [PP] 전처리 내역 조회 — `ZRB1PP0001` (조회)

플랜트/플랜트위치/조회기간을 조건으로 매일 자정 실행된 전처리 배치잡 내역(`ZTB1PP0015`)을 조회합니다. 불용재고가 전처리 설비 용량을 넘어서면 최댓값으로 제한하는 로직을 포함합니다.

### 2. [PP] 자재-공정 연결 — `SAPMZB1PP0003` (트랜잭션)

공정 ID(F4 Help 지원)와 플랜트 코드를 기준으로 자재와 공정을 투입(I)/생산(O) 구분으로 연결·생성·수정·삭제하는 CRUD 프로그램입니다. 공정 순번, 자재 코드, I/O 구분, 메모를 ALV로 관리하며, 저장 시 자재-공정 연결 정보를 DB 테이블에 최종 반영합니다.

### 3. [PP] MRP — `ZRB1PP0004` (트랜잭션)

플랜트·MRP Area·원유·기간을 조건으로 원유 소요량 계획을 실행하는 프로그램입니다. BOM과 PIR을 고려해 모든 PIR을 만족하는 최소 원유 투입량을 선택하고, 재고와 설비 처리량을 반영해 투입량을 보정하며, 확정된 투입량으로 반제품/완제품 생산량을 순방향 계산합니다. 상단 ALV(일자별 원유 투입량)와 PIR 목록 ALV, 소요 산출 내역 TREE(BOM 전개 결과)로 구성됩니다. 관련 테이블: MRP 헤더/아이템(`ZTB1PP0013`/`0014`).

### 4. [PP] 생산오더 관리 — `SAPMZB1PP0005` (트랜잭션)

생산 계획을 선택해 생산 오더로 확정하고, 확정된 오더를 출고·완료 처리하는 프로그램입니다. 같은 날짜의 생산 계획은 오더 전환 시점에 삭제되며, 출고 시점에 설비 일정을 자동 생성합니다. 완료된 생산 오더는 목록으로 출력되고 입고 가능 시 입고 버튼이 활성화됩니다.

### 5. [PP] 작업장 생성 — `ZRB1PP0006` (트랜잭션)

작업장 분류·플랜트 번호·이름을 조건으로 작업장(Work Center) 마스터를 CRUD 처리하는 프로그램입니다. DB 존재 여부에 따라 신규 생성/기존 데이터 기반 생성 팝업으로 분기하며, 모든 DB 반영 전에 사용자 확인 팝업을 거칩니다.

### 6. [PP] 작업장 일정 변경 — `ZRB1PP0007` (트랜잭션)

플랜트·작업장 분류·기간을 조건으로 시간대별 작업장 처리량을 매트릭스(ALV)로 조회하고, 셀 선택 시 작업장 간 처리량 이동을 요청하는 프로그램입니다. 이미 확정된 시간대는 변경 불가 처리되며, 변경량이 원래 값 대비 10%를 초과하거나 설비 설계 한계치를 벗어나면 오류를 반환합니다. 적용된 변경 건은 이동 이벤트 로그에 자동 기록됩니다.

### 7. [PP] 생산오더 관리 — `ZB1PP01` (FIORI, 조회)

Date로 조회한 생산계획 일자의 PLAN/PROD/FINN 수량과 워크센터별 가동률을 표시하는 대시보드입니다. 헤더를 통해 생산을 시작하며 출고·작업장 일정을 자동 생성하고, 생산 완료 시 일단위로 작업장 처리량을 집계해 최종 생산량에 반영합니다. 공정별 가동률 현황과 시간별 가동률 추이를 함께 제공합니다.

### 8. [PP] BOM 조회 — `ZB1PP02` (FIORI, 조회)

계절(봄/여름/가을/겨울)과 기준 자재를 조건으로 역BOM을 조회하는 프로그램입니다. BOM 리스트에서 특정 항목을 클릭하면 기본 정보·투입 자재·생산 자재 탭으로 상세 정보(수량, 단위, 원유 대비 비율, 전체 투입 대비 산출 비율)를 확인할 수 있습니다.

### 9. [PP] 생산 실적 조회 — `ZB1PP03` (FIORI, 조회)

기간(캘린더)을 조건으로 원유 투입량과 완제품 생산량을 집계하는 프로그램입니다. 일자별 원유 투입량을 막대 그래프로 표시하고, 막대 클릭 시 해당 일자의 PIR 대비 생산량 비교 그래프로 전환됩니다.

## 최지수 (SD) — 8개 프로그램

### 1. [SD] 완제품 판매가 결정 — `SAPMZB1SD0003` (트랜잭션)

유효시작일 기준으로 제품별 판매가를 생성·저장하는 프로그램입니다. 마진율을 개별/일괄 적용할 수 있고, 계산 시 MOPS 고시 가격과 세금 정보를 반영한 프리미엄가가 산출됩니다. 최근 5일간의 제품별 기본 판매가 변동 추이를 그래프로 제공하며, MOPS 조회·정부고시가 조회 버튼으로 외부 기준가를 확인할 수 있습니다.

### 2. [SD] 출하 준비 전환 — `SAPMZB1SD0004` (조회)

상태가 REQ(출하 대기)인 판매오더를 출하예정일 기준으로 조회해 RDY(출하 준비) 상태로 전환하는 프로그램입니다. 출하 임박 건은 별도 경고 메시지를 표시하며, RDY 전환 이후에는 고객의 주문 취소가 불가능합니다.

### 3. [SD] 주문 관리 — `ZRB1SD0001` (조회)

물류센터를 선택해 해당 센터에서 발생한 판매오더만 조회하는 프로그램입니다. BP 노드를 클릭하면 해당 거래처의 판매오더를 상태별(REQ/RDY/LOD/BIL/CLO)로 구분해 표시하고, RDY 상태 오더는 툴바의 출고하기 버튼으로 출고 프로그램으로 이동합니다.

### 4. [SD] 출고 관리 — `SAPMZB1SD0001` (트랜잭션)

주문 관리 프로그램에서 넘어온 판매오더를 부피 측정 후 출고 처리하는 프로그램입니다. 부피 측정 결과 반영 후 저장 버튼이 활성화되며, 출고 완료/미출고 건을 아이콘 색상으로 구분해 조회할 수 있습니다.

### 5. [SD] 청구 관리 — `SAPMZB1SD0002` (조회)

출고 완료된 판매오더를 대상으로 청구서(계산서)를 생성하는 프로그램입니다. 출고 미완료/미청구/청구완료/입금완료 상태를 아이콘으로 구분하며, 미청구 건을 선택해 신규 청구를 진행하면 청구 헤더·아이템 정보와 총 금액을 요약해 보여줍니다.

### 6. [SD] 주문 생성 앱 — `ZPB1SD01` (FIORI)

기존/신규 고객 구분 → 물류센터(픽업) 선택 → 제품 및 수량 선택 → 검토 4단계로 판매오더를 생성하는 FIORI 앱입니다. 픽업 요청일은 최소 2일 이후로 제한되며, 영업일 10일 이내 긴급 주문은 제품별 주문 가능 수량을 제한합니다.

### 7. [SD] 주문 조회 및 취소 — `ZPB1SD02` (FIORI, 조회)

BP ID로 해당 고객의 판매오더를 출하예정일 기준으로 조회하는 프로그램입니다. 오더 상태를 진행중(REQ/RDY/LOD)/완료(BIL/CLO)로 필터링할 수 있고, 출하예정일까지 11일 이상 남은 주문만 취소가 가능합니다.

### 8. [SD] 판매 분석 앱 — `ZPB1SD03` (FIORI, 조회)

전체/거래처별/물류센터별 탭으로 판매 실적을 분석하는 대시보드입니다. 총 매출액·총 판매수량·전월 대비 증감률 등 KPI와 월별 매출 추이, 제품군별 매출 비중을 확인할 수 있습니다.

## 이상윤 (FI) — 8개 프로그램

### 1. [FI] 판매 전표 관리 프로그램 — `ZRB1FI0004` (트랜잭션)

판매 관련 참조문서(판매오더·출고·청구 등)를 조회해 전표 헤더/아이템을 생성하는 프로그램입니다. 참조 테이블에서 필요한 데이터를 자동으로 채우고, 차변/대변 금액을 DO_SUM으로 집계해 확인한 뒤 전표를 생성합니다.

### 2. [FI] 생산 전표 관리 프로그램 — `ZRB1FI0003` (트랜잭션)

생산 관련 참조문서를 조회해 전표를 생성하는 프로그램입니다. 구조와 동작 방식은 판매 전표 관리 프로그램과 동일하며, 참조 대상만 생산 프로세스 문서로 다릅니다.

### 3. [FI] G/L 계정 조회 프로그램 — `ZRB1FI0006` (조회용)

회사코드 필수 입력 후 G/L 계정번호 범위·계정 분류(B/S, I/S)·전기키 그룹으로 계정을 조회하는 프로그램입니다. 신규생성/계정삭제/삭제복구 기능을 EDIT 모드에서 제공합니다.

### 4. [FI] 내부 공시용 손익계산서 프로그램 — `SAPMZB1FI0003` (조회용)

회계기간·연도를 조건으로 손익계산서를 Tree 구조(기능별 → 월별 상세)로 조회하는 프로그램입니다. 항목을 더블클릭하면 관련 전표 아이템 내역까지 드릴다운됩니다.

### 5. [FI] 공급업체·운송업체 구매 현황 프로그램 — `SAPMZB1FI0004` (조회용)

구매 관련 BP(공급업체·운송업체)의 거래 내역을 등급·상태 아이콘으로 표시하는 프로그램입니다. BP를 더블클릭하면 구매거래 내역 요약과 구매 전표 아이템 내역이 드릴다운됩니다.

### 6. [FI] AR(외상매출금) 반제 프로그램 — `ZPB1FI10` (FIORI, 트랜잭션)

거래처·국가코드·거래처 담당자로 검색해 미결제/부분반제/입금완료 건을 반제 처리하는 프로그램입니다. 반제할 금액을 입력하고 '입금'을 누르면 반제 전표가 생성되며 상태가 자동 전환됩니다.

### 7. [FI] MOPS 조회 프로그램 — `ZPB1FI11` (FIORI, 조회용)

현재 날짜 기준 7일 전까지의 MOPS(국제 석유제품가) 데이터를 제품별로 조회하는 프로그램입니다. 최신 거래일자·전일 대비 최대/최저 등락 제품을 KPI로 표시합니다.

### 8. [FI] 재무상태표(외부 공시용) 프로그램 — `ZPB1FI12` (FIORI, 조회용)

회사코드·회계연도·기준월을 조건으로 재무상태표를 조회하는 프로그램입니다. 자산·부채·자본 데이터를 차트와 표로 제공하며, PDF 다운로드를 지원합니다.

## 류우석 (CO) — 8개 프로그램

### 1. [CO] 원유 소비 우선순위 시뮬레이터 — `SAPMZB1CO0005` (조회)

기준일·플랜트를 기준으로 계절별 공정 수율표, BCU·촉매 단가, 환율, 공정비를 결합해 WTI/DUBAI/MAYA 원유별 평균단가와 소비 우선순위를 산정하는 시뮬레이션 프로그램입니다. 시뮬레이션 결과는 `ZTB1CO0005` 테이블에 저장되어 재조회할 수 있습니다.

### 2. [CO] 공정 기반 계획/실적 비용 등록 — `ZRB1CO0006` (트랜잭션)

PP 공정/생산 실적을 기준으로 원유·BCU·촉매·공정비를 계산해 계획(PROD)은 CO05, 실적(FINN)은 CO06 테이블로 생성·저장하는 프로그램입니다. 최근 5일 처리 상태를 아이콘으로 표시하고, 계산 시 당일 환율을 반영합니다.

### 3. [CO] 공정 계획/실적 비교분석 — `ZRB1CO0007` (조회)

CO05 계획 원가와 CO06 실적 원가를 결과물ID 기준으로 비교해 투입비·촉매비·공정비·산출량·수율의 차이를 분석하는 프로그램입니다. 차이 발생 행만 색상/아이콘으로 강조하고, 비교 결과를 엑셀로 다운로드할 수 있습니다.

### 4. [CO] 제품별 원가 계산 및 등록 및 조회 — `SAPMZB1CO0003` (트랜잭션)

CO05/CO06 공정 원가를 조회해 제품별 임시 원가를 계산하고, 검토 후 제품별 원가 요약(CO07)과 상세(CO08)로 등록하는 4탭 구조 프로그램입니다. 등록 전 CO07/CO08/이동문서 중복을 검증하며, 그래프 탭에서 제품별 단위원가 추이를 조회합니다.

### 5. [CO] 원유 분석 조회 및 참고 매핑 — `ZRB1CO0004` (조회)

CO05/CO06 공정 원가와 CO07/CO08 등록 원가를 연결 조회하고, 총원가와 상세 구성금액의 정합성을 검증하는 사후 분석·검증 프로그램입니다. 검증 버튼으로 공정 데이터를 기준으로 총액과 구성금액, 참조/비율 누락을 점검합니다.

### 6. [CO] 제품별 순이익 조회분석 — `ZPB1CO01` (FIORI, 조회)

SD 판매 매출과 MM 출고원가를 OData로 집계해 회계연도/기간/제품/판매오더 기준 제품별 매출·출고원가·순이익·마진율을 조회하는 Fiori 수익성 분석 앱입니다. 원가 0건, 수량 0건, 과대 마진 항목을 데이터 검증으로 표시합니다.

### 7. [CO] 기업 수익성 분석 — `ZPB1CO02` (FIORI, 조회)

판매기준 원가와 공정기준 원가를 한 화면에서 비교해 총매출·원가·이익·원가차이를 KPI로 제공하는 종합 대시보드입니다. 판매단가/판매수량/DAYUC/수율/생산량 조건을 바꿔 예상 매출·원가·이익을 미리 계산해보는 수익성 시뮬레이션 탭도 포함합니다.

### 8. [PP] 작업장 CRUD — `ZPB1PP04` (FIORI, 트랜잭션)

WorkCenter 마스터를 FIORI에서 조회하고 신규 생성해 Classic OData 서비스를 통해 PP 작업장 기준 테이블에 저장하는 앱입니다.

## 정나연 (FI) — 8개 프로그램

### 1. 전표대시보드 프로그램 — `ZRB1FI0001` (조회)

구매/판매/생산에서 발생하는 모든 전표, 기타 전표, 역분개된 전표를 조회하는 프로그램입니다. 회사코드·회계연도로 조회하며, 전체/구매/판매/생산 전표를 라디오 버튼으로 필터링하고, 역분개 사유를 입력해 역분개 전표를 생성할 수 있습니다. 참조문서번호 핫스팟 클릭 시 SD/MM/PP 상세내역을 팝업으로 확인합니다.

### 2. 구매전표 생성 프로그램 — `ZRB1FI0002` (트랜잭션)

구매에서 발생한 문서를 참조해 전표를 수동 생성하는 프로그램입니다. 시점별 라디오버튼과 참조문서번호로 조회 조건을 구성하며, 참조 테이블 행을 더블클릭하면 전표 아이템이 자동 생성됩니다. 차변/대변 동일 필드는 금액을 합산(COLLECT)해 하나의 행으로 출력합니다.

### 3. 지급 및 AP 반제 프로그램 — `ZPB1FI01` (FIORI, 트랜잭션)

공급업체 목록을 전체/필터(BP명·국가코드·담당자명) 조회하고 상세 패널에서 미지급/지급완료 건을 확인·지급 처리하는 프로그램입니다. 지급 버튼 클릭 시 실제 지급액을 재확인하는 팝업을 거쳐 반제 전표를 생성합니다.

### 4. 환율조회 프로그램 — `ZPB1FI02` (FIORI, 조회)

조회날짜 기준 환율값·전일 대비 변동폭·30일 평균 환율을 KPI로 표시하는 프로그램입니다. 7일/30일 단위로 line chart를 전환할 수 있고, 환율 최댓값/최솟값을 입력해 차트 y축 범위를 조정할 수 있습니다.

### 5. 전표 수동 생성 프로그램 — `SAPMZB1FI0001` (트랜잭션)

회사코드·회계연도·전표유형·전기일 등을 입력해 전표 헤더를 작성하고, 계정 유형(고객/공급업체/G/L)에 따라 활성화되는 입력 필드로 전표 아이템을 생성하는 프로그램입니다. 계정코드에 매핑된 세금코드를 자동 세팅해 세금 라인을 동시 생성하며, 차대변 불일치 시 저장이 불가합니다.

### 6. 재무상태표 조회 프로그램 — `ZRB1FI0005` (조회)

회사코드·회계연도·전기간을 조건으로 재무상태표를 조회하는 프로그램입니다. Splitter로 자산(좌)/부채(우측 상단)/자본(우측 하단) 3분할 T계정 형태를 구현했고, ALV Tree로 대분류→중분류→계정을 계층 표시하며 대차 일치 여부를 KPI로 확인합니다.

### 7. 손익계산서 조회 프로그램 — `ZPB1FI03` (FIORI, 조회)

회사코드·회계연도·시작월/종료월을 조건으로 매출액·매출총이익·영업이익·당기순이익 4개 핵심 지표를 KPI로 제공하는 프로그램입니다. 계정과목 그룹별 당기/전기 비교(막대 차트), 매출원가·판관비·영업이익 구성비(도넛 차트)를 함께 제공합니다.

### 8. 세금 추적 조회 프로그램 — `SAPMZB1FI0002` (조회용)

회사코드·회계연도·전표 전기일·전표유형·세금코드·공급업체 코드 등으로 세금 전표를 조회하는 프로그램입니다. 전체 세금 건수와 세금코드별 건수, 총 납부세액을 KPI로 표시하고, 월별 납부세액 추이를 차트로 제공합니다.

## 강효창 (PM) — 8개 프로그램

### 1. 서비스 헤더 생성 및 승인 처리 프로그램 — `SAPMZB1MM0001` (트랜잭션)

서비스 운송 현황에 맞춰 서비스 헤더 데이터를 생성하고 승인 처리하는 프로그램입니다. 서비스 아이템 상태에 따라 헤더 데이터 생성이 가능하며, 운송 현황(예: USA TANK 원유 입고 완료)을 확인해 승인 처리 후 입고 처리 프로그램으로 이동할 수 있습니다.

### 2. 서비스 오더 생성 및 조회 프로그램 — `SAPMZB1MM0005` (트랜잭션)

Dropdown(NB 표준 구매오더/SV 서비스 오더)에 따라 서브스크린을 다르게 처리해 서비스 헤더/아이템, 담당 운송업체, 운송 자재, 운송 경로, 서비스 패키지를 조회·생성하는 프로그램입니다. 운송 경로는 CL_GUI_PICTURE로 지도 이미지를 통해 확인할 수 있고, 구매업체와 운송업체 국가코드가 다르면 오류 메시지를 표시합니다.

### 3. 자재 운송 소요 계획 조회 프로그램 — `ZRB1SD0006` (트랜잭션)

물류센터 입장에서 월별 출고 예정량·운송 요청량을 파악해 본사에 부족분만큼 자재 운송을 요청하는 프로그램입니다. "월별 재고량 = 현재고량 - 월별 출고 예정량 + 월별 운송 요청량" 공식으로 재고량을 계산하며, 운송 필요량 필드를 클릭해 원하는 만큼 운송 요청을 보낼 수 있습니다.

### 4. 본사 운송 요청 승인 프로그램 — `ZRB1SD0007` (트랜잭션)

요청 상태가 운송 예정(R)인 데이터와 운송 확정(A)인 데이터를 조회하는 프로그램입니다. 확정 시 자재 보충 계획 ALV에 데이터가 추가되고 본사 재고량이 업데이트되며, 최종 저장 시 확정된 운송 문서만큼 생산 요청 문서가 생성됩니다.

### 5. PIR 조정 프로그램 — `ZRB1PP0002` (트랜잭션)

날짜/자재/수량을 입력해 PIR 데이터를 등록하는 프로그램입니다. PIR 총합 ALV는 월별 자재 생산 요청량을 합한 값을 모은 Dynamic Table이며, 유형을 수요 계획(01)/운송 보충 계획(02)으로 나눠 SUBTOTAL로 조회합니다.

### 6. 재고 현황 관리 프로그램 — `ZPB1MM05` (FIORI, 조회)

자재·저장창고를 선택해 재고 현황(총재고/가용재고/증발감손/전환중/총평가금액)을 KPI Tile과 하단 테이블로 확인하는 프로그램입니다. 하단 테이블을 클릭하면 재고 흐름 분석 화면(날짜별 재고 흐름 그래프, 재고 변경 타임라인)으로 이동합니다.

### 7. 프로세스 플로우 조회 프로그램 — `ZPB1SD05` (FIORI, 트랜잭션)

모듈과 참조문서번호를 입력해 연관된 프로세스 및 프로그램 목록을 확인하는 프로그램입니다. 실행 대기인 프로세스를 클릭해 해당 프로그램을 실행할 수 있고, 저장 후 돌아오면 프로세스 타일이 실행 완료 상태로 바뀝니다.

### 8. 본사 재고 보충 요청 생성 및 출하 — `ZPB1SD04` (FIORI, 트랜잭션)

자재·저장창고를 선택해 GO 버튼으로 현황을 조회하고, 승인 완료된 자재 데이터를 즉시 출하 처리하는 프로그램입니다. 신규 생성 버튼으로 본사가 직접 자재 보충 요청 문서를 만들면 자동 승인 완료되어 즉시 출하가 가능합니다.
