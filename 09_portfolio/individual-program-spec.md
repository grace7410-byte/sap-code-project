## 1. [MM] 구매오더 프로그램 — `SAPMZB1MM0004` (트랜잭션)

- **T-Code**: ZB1MM0004 · 작성 2026.04.29, 수정 2026.07.02

공급업체별로 산정된 "최적 원유 조건"을 SAP GUI와 연동해 실시간으로 시각화하고, 복잡한 정유 연산품 수율을 고려해 구매 의사결정을 지원하는 구매오더 CUD 통합 관리 프로그램입니다.

- 공급업체 마스터(BP 마스터·조정계정·벤더마스터) 인풋 필드 서치헬프 연동 — 상세 정보 팝업 조회 및 "공급업체 선택" 클릭 시 헤더에 자동 반영
- 공급업체별 자재 선택 탭스트립에서 해당 업체의 구매 가능 원유 데이터로 자동 전환, 서브스크린 아웃풋필드로 표시
- 구매오더 아이템: 탭스트립에서 자재 직접 선택 시 단가·통화·기본단위 자동 할당, 총액 자동 계산
- 항목 추가 시 공급업체별 최적화 자재 여부를 검증하는 유효성 체크(팝업 경고 + 에러 핸들링으로 단가/단위 오할당 차단)
- 탭 구성: TAB1 (환매율 연동 원화 자동 환산 ALV), CHART(유종별 드롭다운 수율 조회), TAB2(계절 가중치 반영 원유 수율 ALV+차트)
- 저장 전 "오류 확인" 유효성 검증 버튼, 저장 시 총액 팝업 재확인 후 DB 반영
- 문서유형 SV 전환 시 "서비스오더" 프로그램으로 메모리 ID 전달 및 화면 자동 전환 — MM(01) ↔ MM(03) 연동 지점
- 조회/삭제: 승인 전까지 수정 가능, 헤더 단건·아이템 다건 삭제 지원(ALV EDIT 모드), 삭제는 조회성으로 확인 후에만 가능
- **관련 테이블**: 구매 최적화 조건(ZTB1MM0005), 구매오더 헤더(ZTMM0006)/아이템(ZTB1MM0007), 공급업체 관련(ZTB1SD0001/0002, ZTB1MM0004), 자재 관련(ZTB1MM0001/0002, ZTB1PP0003)

## 2. [MM] 부피측정 조회 프로그램 — `ZRB1MM0001` (조회)

정유 산업의 물류 핵심인 부피 측정 데이터를 구매/판매/생산 오더와 연계해 실시간 통합 조회하는 프로그램입니다. 실측치(온도·밀도·보정계수)와 환산치를 관리해 물류 신뢰성을 확보합니다.

- Selection-screen: 오더 유형·자재코드·문서번호·측정 날짜·플랜트·저장위치 조건별 서치헬프
- Splitter 컨테이너로 좌측에 선택 문서유형 텍스트, 우측에 구매/판매/생산 오더를 LEFT OUTER JOIN한 3개 모듈 ALV를 문서번호/항목/BP/날짜 기준으로 동적 조회
- FIELD-SYMBOLS로 대량 데이터 조회 속도 최적화, 검색 후 불필요 필드는 DEL 플래그 처리로 메모리 효율화
- ZMSNO(측정번호) 유무·ORDQTY 양수/음수로 입고(GR)/출고(GI) 자동 판별, 신호등 색상(측정 완료/대기/필수)으로 후속 업무 인지 지원
- **하이라키 뷰(2편 기능 확장)**: `CL_DD_DOCUMENT` + `add_link`로 상단 컨테이너에 시각적 상태 바 구성, ALV 클릭 시 완료 단계별 세부 헤더/아이템 동적 호출. 판매(3단계: 오더-부피측정-출고), 생산(4단계: 생산계획-생산오더-부피측정-입출고), 구매(4단계: 최적화조건-구매오더-부피측정-입고) 프로세스를 `REUSE_ALV_HIERSEQ_LIST_DISPLAY`로 1:N 계층 조회, PDF 문서 출력 지원
- **관련 테이블**: 부피측정(ZTB1MM0020), 구매최적화조건(ZTB1MM0005), 구매오더 헤더/아이템(ZTB1MM0006/0007), 판매오더 헤더/아이템(ZTB1SD0006/0007), 생산계획/오더(ZTB1PP0013/0014), 자재이동 문서(ZTB1MM0011/0012)

## 3. [MM] 입고 관리 프로그램 — `SAPMZB1MM0002` (조회)

한 달 반의 구매/운송 시점에 걸쳐 선적입고(L)·실측입고(P)·로스처리(S) 3단계를 유기적으로 처리하고, 자재 전표·회계 전표를 실시간 동기화하는 프로그램입니다.

- 표준 다큐먼트 객체로 상단에 물류 진행 단계(1차 운송 → 선적 부피측정 → 선적입고 → 2차 운송 → 실측 부피측정 → 플랜트 실측입고 → 송장검증)를 상태 바로 시각화
- 이동유형별 분기: 선적입고(101, 재고유형 T-운송중), 실측입고(321, S-품질대기, 증발손실 zloss 자동 연산), 로스처리(551, 코스트센터 TRANSPORT_LOSS_COST 자동 매핑)
- 운송현황 링크 클릭 시 서비스 PO 기반 운송현황 팝업 → 승인 처리 버튼으로 서비스 승인 프로그램(결재 프로그램) 이동, 복귀 시 화면 리프레시
- 선적입고/실측입고 링크(핫스팟) 클릭 시 아이템 추가 확인 팝업 → "예" 선택 시 부피측정 데이터를 기준으로 수량 자동 반영, 증발 손실이 있으면 기존 수량과 차이만큼 "손실량" 필드에 자동 적용
- CDS View로 당일 환율 적용 단가·금액 자동 계산
- `NUMBER_GET_NEXT`로 자재전표 번호 신규 채번(자재전표 헤더/아이템, 재고 변동 펑션 순차 수행) — 실측입고 완료 시 (1)자동 전표 생성 (2)총재고·총평가금액(원화)·이동평균가 자동 갱신
- 송장검증 링크: 검증 불가 시 RED, 가능 시 GREEN 핫스팟으로 상태 전환
- **관련 테이블**: 부피측정(ZTB1MM0020), 구매오더 헤더/아이템(ZTB1MM0006/0007), 자재이동 문서 헤더/아이템(ZTB1MM0011/0012), 송장검증 문서 헤더/아이템(ZTB1MM0013/0014)

## 4. [MM] 송장 검증 프로그램 — `SAPMZB1MM0003` (조회)

가송장 데이터를 기준으로 실시간 환율 계산, 데이터 유효성 검증, DB 상태 변경 및 전표 생성(FI 연동), PDF 리포트 출력을 수행하는 프로그램입니다.

- 물품대금/부가세 처리 시점: 실제 입고된 실물 자재문서(GR) 기준 금액 교차 검증
- 운송 부대비용 처리 시점: 물품대금과 달리 자재 마스터 코드(MATNR)가 없을 수 있어, 구매오더 번호(EBELN)와 서비스오더 내역 기준으로 루프를 돌며 대비 아이템 생성
- 금액 입력 시 실시간 환율 변환, 덤프 방지 및 실시간 밸런스/신호등 계산, ALV 프로토콜 객체(Log)에 에러 메시지 바인딩·누적 처리
- 송장 유형(물품대금 vs 관세/부가세 vs 운송 부대비용)별 검증 신호등 및 활성화 로직 분리
- 잔액 계산 신호등: 가송장 총액과 입력 금액 차이가 0이면 초록불, 아니면 빨간불 세팅
- 증빙일자는 반드시 구매오더 생성일보다 미래(또는 동일)여야 하는 시간적 선후 관계 제약 — PAI 이벤트 시점에 외화 금액 입력 시 즉시 환율을 곱해 원화 총액 실시간 산출
- 검증 완료 시 펀션모듈 호출로 전표 헤더/아이템 반영(ZFB1FI0002)
- **관련 테이블**: 구매오더 헤더/아이템(ZTB1MM0006/0007), 자재이동 문서 헤더/아이템(ZTB1MM0011/0012), 송장검증 문서 헤더/아이템(ZTB1MM0013/0014)

## 5. [MM] 구매 부피 측정 프로그램 — `SAPMZB1MM0006` (조회)

구매오더 품목마다 부피를 측정·기록하고, 실제 잰 부피와 15℃ 표준 온도로 환산한 부피를 서로 계산해 다음 단계인 입고 처리로 이어주는 프로그램입니다.

- 목록에서 구매오더 품목 줄을 더블클릭하면 품목 번호·수량이 위쪽 입력 칸에 자동 반영
- 측정 번호는 당일 날짜 기준 자동 채번, 같은 구매오더에 오늘 만든 측정이 있으면 그 번호를 이어 쓰고, 처음이면 1차(선적)로 자동 구분, 두 번째는 2차(실측)로 구분
- 온도·밀도는 자재 종류(원유/경유 등)에 따라 위촉값을 채우고, 온도는 계절에 맞는 범위(예: 여름 25~40도, 겨울 영하 5~10도) 안에서 지정
- "보정계수 계산" 버튼으로 부피 표준 온도(15℃) 기준 환산 계수 산출
- 화살표 두 개로 부피를 서로 계산 — 왼쪽 화살표는 구매오더 수량 기준으로 환산부피를 먼저 정하고 그 값으로 실측부피를 역산, 오른쪽 화살표는 실제로 잰 실측부피 기준으로 환산부피를 산출
- 저장 누르면 온도·밀도·부피·보정계수 중 비어있는 값이 있는지 확인, 몇 번째 측정인지(처음/두 번째/그 이상)에 따라 확인 문구를 다르게 표시
- 목록의 진행 상태 칸을 색상으로 표시(빨강=측정 대기, 강조=선적입고까지 완료, 초록=실측입고까지 완료)
- **관련 테이블**: 부피 측정 기록, 보정계수 참조, 구매오더 품목

## 6. [MM] 결재 프로그램 — `ZRB1MM0002` (조회)

구매오더에 대한 결재(승인) 내역을 조회·상태 변경·반려하고, 서비스 주문 승인 화면으로 넘어가는 것까지 한 화면에서 처리하는 프로그램입니다.

- 조회 조건(승인 상태·구매오더 번호·승인 번호·상신일) 입력 후 실행하면 구매오더 정보와 그동안의 결재 내역을 하나로 합쳐 목록으로 표시
- 서비스 주문을 새로 만들고 나면 뜨는 확인 창에서 "예"를 누르면, 방금 만든 하나만 담긴 목록으로 이 프로그램이 곧바로 열림. 반대로 이 프로그램을 따로 실행하면 그동안 올라온 전체 결재 내역이 보임
- 결재 상태 4종(대기·승인·반려·취소) — 아직 "대기" 상태건만 값 바꿀 수 있고, 이미 처리된 건은 못 바꾸도록 막음. "반려" 선택 시 사유 필수 입력
- 저장 시 목록의 표시가 완료 처리(초록색)로 바뀌고, 승인되면 연결된 구매오더 품목의 상태도 같이 바뀜 — 서비스 주문에서 넘어온 건이면 원래 구매오더 쪽 상태까지 함께 맞춰짐
- 화면 위쪽 '서비스 승인' 버튼으로 연결된 서비스 주문의 승인 화면으로 바로 넘어감 — 구매오더 승인에 이어 서비스 주문 승인까지 자연스럽게 이어지는 구조 (MM(01)↔MM(03) 연동)
- '구매오더 생성' 버튼은 확인 창을 거쳐 구매오더 프로그램을 새로 만드는 화면으로 열고, '오더 수정'/'오더 삭제' 버튼은 같은 프로그램을 수정 또는 삭제 화면으로 열어줌
- **관련 테이블**: 결재 내역, 구매오더 헤더·품목

## 7. [MM] 원산지 지도 — `zpb1mm01` (FIORI, 조회)

전 세계 원유가 나는 곳(미국 텍사스, 사우디 페르시아만, 멕시코 캄페체만)을 지도 위에 표시하고 그 지역 공급업체 정보를 보여주는, 원산지를 기준으로 공급업체를 고르는 첫 화면 역할의 프로그램입니다.

- 지도 위 세 곳의 원유 산지를 아이콘으로 표시, 주변 공급업체·운송업체 위치도 작은 점으로 함께 표시
- 산지 아이콘 클릭 시 그 나라의 공급업체 목록이 팝업으로 표시(주소가 있고 공급업체로 등록된 곳만 필터링) — 팝업은 최초 1회만 불러와 이후 재사용, 빠른 재호출
- 팝업에서 공급업체 하나를 클릭하면 그 업체 정보를 가지고 '구매 의사결정 지원' 프로그램(zpb1mm02)으로 바로 이동 — 지도에서 넘어가는 경우와 zpb1mm02를 따로 실행하는 경우가 동일하게 동작하도록 구현
- **관련 테이블**: 공급업체 위치 정보, 원산지 위치 정보

## 8. [MM] 구매 의사결정 지원(구매최적화조건) — `zpb1mm02` (FIORI, 조회)

공급업체별 원유 조건(가격, 걸리는 기간, 예상 이익)을 버블차트로 한눈에 비교하고, 마음에 드는 조건을 최종 확정할 수 있는 프로그램입니다. 원산지 지도에서 특정 공급업체를 골라 넘어오거나, 이 프로그램만 따로 실행해도 동일하게 동작합니다.

- 검색 조건(공급업체·원산지·자재)을 좁히면 왼쪽 요약 카드(최저 가격·최단 기간·평균값)와 버블차트·목록이 함께 갱신
- 버블차트는 가격·걸리는 기간·예상 이익을 한 화면에 동시에 표현, 공급업체마다 다른 색으로 구분 — 버블 클릭 시 해당 업체 조건 기간을 자동으로 알려주고, 화면을 열 때 데이터가 몰린 구간을 자동 확대
- 요약 카드 값은 서버에 다시 묻지 않고 화면에 보이는 목록 값만으로 그 자리에서 다시 계산 — 조건을 바꿀 때마다 화면이 즉시 갱신
- '구매 원유 확정' 버튼으로 최종 조건 확정 저장 — 중간 점검 피드백 반영해 새 줄 추가 방식에서 기존 줄의 표시만 바꾸는 방식으로 변경(예전 방식은 코드에 남겨 비교 가능하도록 유지)
- 저장 후 목록·버블차트가 화면 전환 없이 바로 새로고침되며 '선택' 표시가 곧바로 나타남
- **관련 테이블**: 원유 구매 조건, 공급업체 위치 정보

## 9. [MM] 부피 측정 프로그램(모바일 스캔) — `zpb1mm04` (FIORI, 조회)

휴대폰이나 태블릿으로 원유 탱크에 붙은 바코드를 스캔해서 부피를 측정하고 기록하는 프로그램입니다. 사무실 컴퓨터용 부피 측정 프로그램(5번)과 하는 일은 같지만, 현장에서 스캔 한 번으로 바로 처리할 수 있게 만들었습니다.

- '문서 생성' 버튼으로 입력 화면을 열고 바코드 스캔 안내 표시
- 탱크에 붙은 바코드를 스캔하면 그 안에 담긴 문서 종류·번호·항목 번호를 읽어서 해당 구매오더 정보(플랜트·저장위치·자재)를 자동으로 화면에 반영
- 실측 부피는 주문 수량으로, 밀도는 자재 종류에 따라 정해진 값으로, 온도는 지금 계절에 맞는 범위 안에서 자동으로 채워지며 필요하면 직접 수정 가능
- 값이 채워지면 곧바로 보정계수와 환산 부피, 실측 부피와의 차이를 계산해서 보여줌 — 차이가 늘었는지 줄었는지에 따라 숫자 색이 달라짐
- '측정 문서 확정' 버튼으로 저장 확인 창을 띄우고, 확정하면 오늘 날짜를 기준으로 측정 번호가 자동 생성되어 저장 — 같은 구매오더에 대해 오늘 이미 만든 기록이 있으면 이번 건은 2차(실측), 없으면 1차(선적)로 자동 구분
- 저장 완료 후 저장된 측정 번호·유형 안내와 함께 목록이 새로고침 — 목록에서는 측정번호로 찾을 수도, 측정일·온도·밀도 등으로도 검색 가능
- **관련 테이블**: 부피 측정 기록, 구매오더 품목 정보
