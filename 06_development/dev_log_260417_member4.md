## 2. 기술적 트러블슈팅
### 이슈 1: Search Help(F4)의 불필요한 데이터 노출 및 가독성 저하
- **현상**: 표준 F4 Help 사용 시 비즈니스 로직과 무관한 불필요한 필드나 데이터까지 리스트에 노출됨
- **원인**: 표준 Search Help의 필터링 미흡 및 원천 데이터의 가공 부재
- **해결**: Dropdown 리스트 구성 시 DB에서 가져온 로우 데이터를 내부 테이블에서 한 차례 가공(Filtering/Sorting)한 후 사용자에게 필요한 핵심 값만 제공하도록 로직 수정

### 이슈 2: 유효성 체크 로직 내 탈출 조건 누락으로 인한 런타임 덤프(Dump)
- **현상**: 입력값 검증 중 특정 조건에서 프로그램이 비정상 종료되는 현상 발생
- **원인**: 유효한 선택 값의 존재 여부는 확인하였으나, 값이 없을 경우 로직을 중단하거나 예외 페이지로 이동시키는 탈출 코드(Exception Exit)가 누락되어 후행 로직에서 Null 참조 발생
- **해결**: 검증 단계마다 적절한 탈출 코드를 추가하고, 오류 발생 시 메시지 처리와 함께 로직을 안전하게 종료하도록 개선하여 시스템 안정성 확보
