### [ ZRB1PP0002, ZRB1SD0006, ZRB1SD0007 ] PIR 스크린 레이아웃 통일 및 UI/UX 표준화

* **사용자 피드백 및 메시지 처리 가이드라인 표준화**
  * 데이터 생성 시 발생하는 안내 팝업 메시지 및 시스템 에러 메시지가 팝업 모달 대신 화면 하단 메시지 바(Message Bar)에 통일되게 출력되도록 인터페이스 세팅을 조정하였다.
  * 사용자 가이드를 위한 전용 안내 팝업 다이얼로그(Dialog)를 추가 생성하여 초기 진입 편의성을 한 단계 향상시켰다.

* **ALV 그리드 상태 초기화 및 시각적 요소 일관성 확보**
  * 최종 데이터 저장 프로세스 완료 시 ALV 테이블 초기화 로직을 수행하도록 처리하였다. 기존 테이블 내 하이라이트 잔상을 제거함과 동시에 DB 테이블로부터 최신 데이터를 재조회(Re-fetch)하여 화면에 갱신 표시되도록 구현하였다.
  * ALV 그리드 타이틀(Grid Title) 속성을 정의하고 얼룩말 형태의 행 교대 속성(ZEBRA)을 허용하였으며, 테마 하이라이트 컬러 체계를 타 모듈 화면과 일률적으로 통일시켰다.

* **이벤트 인터랙션 및 툴바 커스텀 명령 표준화**
  * 기존 핫스팟(HOTSPOT) 클릭으로 동작하던 데이터 상세 조회 이벤트를 더블클릭(DOUBLE-CLICK) 동작 방식으로 일괄 변경 및 조정하였다.
  * ALV 사용자 정의 커맨드(USER-COMMAND) 기능 내 행 삭제 아이콘 속성을 표준 규격인 DELETE_ROWS로 수정 반영하였다.

### [ ZPB1SD04 ] Fiori 기반 운송 요청 문서 생성 및 즉시 출하 처리 프로그램 설계

* **OData 서비스 아키텍처 및 엔티티 세트(EntitySet) 구축**
  * SAP Fiori 애플리케이션과의 실시간 인터커넥션을 위해 OData 서비스를 신규 생성하고, 핵심 데이터 모델인 운송 요청 세트, 자재 마스터 세트, 저장창고 마스터 세트 등 총 3개의 EntitySet을 성공적으로 정의하였다.
  * 자재 마스터 및 저장창고 마스터 엔티티 세트를 UI의 FilterBar 내 MultiCheckBox 드롭다운 목록 구조로 바인딩하여 다중 선택 검색이 가능하도록 레이아웃을 구성하였다.

* **Fiori UI 데이터 바인딩 및 조회 프로세스 연동**
  * 사용자가 화면 상의 GoSearch 검색 버튼을 트리거할 때, 운송 요청 엔티티 세트의 GET_ENTITY_SET 메서드가 실행되도록 구현하였다. 백엔드로부터 수신된 운송 요청 메타 데이터를 Fiori 표준 컴포넌트인 sap.m.Table 컨트롤에 적재 및 동적 인서트 처리 완료하였다.

## 2. 발생한 기술적 오류 및 조치

- **오류 01**: ALV 툴바 내 삭제 버튼 클릭 이벤트 처리 중, 엔드유저가 집계용 소계(SUBTOTAL) 또는 합계(TOTAL) 행을 선택한 상태에서 삭제 요청 커맨드를 실행할 경우 물리적 테이블 데이터 포인터 불일치로 인해 시스템 덤프 에러(DUMP ERROR)가 유발되는 결함이 발생하였다.
