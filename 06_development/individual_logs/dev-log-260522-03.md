## 2. 발생한 기술적 오류 및 조치
- **오류 1**: 서비스 PO 아이템 오더 총금액 계산 구현 중, 실제 금액 데이터가 존재하는 항목(예: 20번)이 아닌 금액이 없는 항목(10번)에 총금액이 잘못 저장되는 정합성 오류 발생
- **조치 1**: 더블 클릭 이벤트 핸들러에 방어 로직 추가 — DMBTR/NETPR 없는 무효 항목은 CONTINUE로 연산 제외, 정확한 라인 항목 번호(EBELP) 기준 고유 키값으로만 DB UPDATE
- **오류 2**: 부피측정 테이블 필드 및 도메인 수정 후 액티브 오류 1건, 경고 1건 발생
- **조치 2**: (오류) 데이터 요소(ZDVB1MM0001)에서 사용 중이던 필드 삭제 후 액티브화, 이후 재추가로 해결 / (경고) VCF 도메인 타입을 DEC(5,2)→DEC(7,4) 확장 시 출력 길이가 기존(6)으로 고정되던 문제 → output length 8로 수정
- **오류 3**: 마스터 데이터 중 영하 온도(-5도~-0.1도) 입력 시 테이블 키 필드에서 음수 부호 미인식, 음수 허용([Sign]) 옵션 활성화에도 SE16N 데이터 추가 불가
- **조치 3**: SE16N 대신 유지보수 뷰 생성해 일괄 입력으로 우회
- **오류 4**: 유지보수 뷰 데이터 입력 시 온도 단위(ZUNIT)·기준 온도(ZSTD) 필드가 Fixed Value 설명글을 드롭다운 Listbox로 강제 호출, 데이터 길이 초과 및 복사·붙여넣기 오류 발생
- **조치 4**: Screen Painter(SE51)에서 해당 필드 Dropdown 속성 해제. 기준온도 필드는 DEC 타입이라 Listbox 옵션이 뜨지 않아 CHAR로 임시 변경해 속성 제거 후 재차 딕셔너리 연결
