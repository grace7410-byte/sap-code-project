## 1. 진행 내역
- **04.08**: 생산 관련 전표 프로그램을 생성하고 ALV 와 조건조회의 화면을 구성하였다. 효율적인 데이터 처리를 위해 Function Module의 필요성을 인지하고, Function Module 생성을 위한 아키텍처 설계를 구상하기 시작하였다.
- **04.09**: 자동 전표를 생성하는 로직을 Function Module로 구현하였다. 각 모듈에서 프로그램을 사용하는 중에 발생하는 실시간 데이터를 활용하여, Function Module 인터페이스 파라미터로 데이터를 수신한 뒤 자동으로 전표 헤더와 아이템이 생성되도록 로직을 고안하였다.
- **04.10**: Function Module 을 선적 입고 프로그램에서 호출하여 사용할 수 있도록 핵심 소스 코드를 완성하였으며, 이를 기반으로 나머지 프로세스 확장을 진행하였다.

### 📌 세부 내역 및 데이터 구성 예시
- 일반적으로 변동이 없이 생기는 전표가 여러 가지가 있는데, 지금은 그 중에서 한 부분만 진행하였다. 앞으로도 자동 전표를 만들 수 있는 여러 경우들에 대해서 Function Module로 로직을 만들 계획이다.
1) 전표 헤더 생성에 필요한 필드들과 어떻게 하면 연결이 될 지 로직으로 설계하였다.
2) 전표 아이템도 필요한 필드들과 차변, 대변에 따라 달라져야 할 것들이 무엇인지 파악하여 로직을 작성하였다.
3) 추후 Function Module 로직을 짜고, 각 모듈에 배포하여 전표가 정상적으로 생성되는지 확인할 예정이다.
