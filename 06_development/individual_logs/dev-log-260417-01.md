## 1. 진행 내역
1) 자재 운송 소요 계획을 위해 CDS VIEW 와 동적 ALV 기능을 사용하였다.

   1-1) CDS VIEW 로 월별 판매 오더량, 운송 확정량, 운송 요청량을 분리하였다.
   
   1-2) SORT, DELETE ADJACENT 와 동적 TABLE 생성 기능을 통해 CDS VIEW 에 생성된 월 데이터 값만큼 필드를 추가하였다.
   
   1-3) 이후 CREATE DATA ~ LINE OF ITAB 과 해당 DATA 에 대한 FIELD SYMBOL 을 생성하여 동적 TABLE 에 데이터를 넣었다.
   
   1-4) 추가로 운송 필요량과 각 월별 자재 재고량을 내부 계산 로직을 통해 값을 넣었고, 만약 자재 재고량이 음수일 경우 부족분만큼 운송 필요량에 값이 들어가도록 설정하였다. 이때 CREATE_DYNAMIC_TABLE 에서 LVC_T_STYLE 필드를 추가하였고, 이를 기반으로 운송 필요량 셀의 색깔을 빨간색으로 설정하였다.
   
   1-5) 월별 판매량이 떴을 때 이것이 어떤 판매오더로 구성되었는지 확인하기 위해 HOTSPOT CLICK EVENT 로 최지수 개발자의 주문관리 프로그램으로 이동되게끔 설정하였다.
   
   1-6) 운송 필요량 셀에도 HOTSPOT CLICK EVENT 를 설정하였는데, 클릭 시 원하는 수량을 입력하고 요청 시 운송 요청 테이블에 데이터가 추가되게끔 설정하였다.

2) 서비스 헤더 데이터 삭제 기능을 생성하였고, 각 기능 실행 시 메시지 POP-UP 을 띄워서 실행을 확정할지 확인하는 절차를 추가하였다.

### 📌 차후 추가 기능 및 프로그램
- 운송 요청 프로그램을 만들어 운송 요청 테이블과 현 재고를 비교하여 운송 요청을 승인하는 프로세스를 생성할 예정이다.

## 2. 발생한 기술적 오류 및 조치
* **오류 1**: 동적 ALV 생성 과정에서 사용하는 FIELD SYMBOL 구문 처리 중 포인터 미지정으로 인한 ITAB 덤프 에러 발생.
* **조치 1**: 디버깅을 통해 각 로직 실행 시 FIELD SYMBOL 이 정상적으로 ASSIGN 되었는지 체크 로직을 보완하고, 각 개별 로직을 수행한 후 UNASSIGN 처리 조치 완료.
