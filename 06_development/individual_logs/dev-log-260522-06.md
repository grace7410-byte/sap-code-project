## 1. 진행 내역

**[ zpb1fi01 ]** AP 반제 프로그램

1) 구현 완료 영역
   - 공급업체 목록 테이블에 공급업체 정보 출력(BPID, BP명, 국가코드, 주소 등)
   - 공급업체 선택 시 해당 업체와의 거래내역(송장) 하단 테이블 출력
   - 지급확인 필드에 미지급 문서만 지급 버튼 출력
   - 지급하기 버튼 클릭 시 송장번호 파라미터 전달하며 화면 이동, Object Page로 헤더 타이틀에 송장번호 출력, 아이템 내역 블록 출력
   - 하단 TAccount로 T계정 출력: 차변 = 송장아이템 총평가금액(KRW) 합산 → 외상매입금 금액, 대변 = 송장아이템 거래금액(USD) × 현재 환율 → 보통예금 금액, 차변-대변 차액으로 외환차손익 계산(외환차익=대변, 외환차손=차변)
   - 차변 클릭 시 다이얼로그로 거래금액(USD) 합산액·오늘의 환율·지급할 금액 확인 가능
   - 지급금액 및 외환차손익 발생액 확인 가능. 지급버튼 클릭 시 전표 헤더·아이템 CREATE 및 송장상태·원전표 반제처리 UPDATE 처리
2) 구현 예정
