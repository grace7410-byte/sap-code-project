## 1. 진행 내역
1) 서비스 엔트리 헤더 데이터를 운송현황을 현재 날짜와 대조하여 운송 완료 상태일 경우 헤더 데이터를 생성하였다.
2) Splitter Container 기능으로 서비스 아이템과 운송현황 테이블을 분리하였다. 이후 Layout 의 excp_fname 기능을 통해 운송완료/진행중/엔트리 생성되지 않음에 관한 데이터를 신호등으로 표시하였음. Info_fname 기능을 통해 운송현황 데이터 라인이 하이라이트 되도록 설정하였다.
3) 서비스 헤더 데이터 생성 테스트 중 넘버 레인지가 자동으로 올라가는 에러가 발생하였다. SNRO 와 연결된 테이블을 참조하여 테이블 마지막 데이터에 맞게 자동 채번할 계획이다.
4) DataBase View 를 사용하여 서비스 PO 번호에 대응되는 패키지 번호 데이터 필드 데이터만 조회되게끔 설정하였다.
