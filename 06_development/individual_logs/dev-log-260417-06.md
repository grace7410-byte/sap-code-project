## 1. 진행 내역
**[ ZFB1FI0002 ]** 자동 전표 생성 Function Module
- 공급업체 조달 프로세스 시 발생하는 전표가 자동 인터페이스되도록 선적입고, 송장, 지급, 플랜트입고 시점별로 분기 조건을 세분화하여 로직을 구성하였다.

**[ ZRB1FI0001 ]** 전표 대시보드 프로그램
1) 유연한 기능 확장을 위해 프로그램 아키텍처를 기존 Module Pool 방식에서 Report 프로그램 구조로 전환하였다.
2) 데이터 가시성 제고를 위해 전표 헤더 및 아이템 ALV 그리드에 최적화된 필수 필드 중심의 전용 Structure 를 설계 및 적용하였다.
3) Selection Screen 에서 회사코드와 회계연도를 검색 조건으로 설정 조치하였으며, 실행 시 해당 조건에 부합하는 마스터 데이터를 전표 헤더 ALV 에 바인딩하도록 구현하였다.
4) 세부 전표 조회 버튼 트리거 시 상세 검색 조건 제어가 가능한 독자적인 서브스크린이 동적으로 호출 및 종료되도록 프로세스를 구축하였다.
5) 서브스크린 호출 시 메인 화면(Selection Screen)에서 선행 입력된 회사코드와 회계연도 데이터가 PBO 단을 통해 비활성화 필드로 자동 이관 및 유지되도록 연동하였다.
6) 전표 아이템 ALV 내에서 차변과 대변의 시각적 식별성을 극대화하기 위해 LVC_T_STYLE 구조를 활용한 셀 색상 변경 로직을 추가하였다.
7) 계정 유형 필드의 도메인 고유 값을 직관적인 텍스트 형태로 디스플레이하기 위해 GET_DOMAIN_VALUES 함수를 매핑하여 사전을 구성하였다.

## 2. 발생한 기술적 오류 및 조치
- **오류 1**: 버튼 트리거 시 특정 조건에 맞춰 서브스크린이 호출되어야 하나, 프로그램 실행과 동시에 서브스크린이 강제 로드되면서 시스템 덤프 예외 발생.
- **조치 1**: 화면 제어 로직을 검토하여 공백 서브스크린을 사전에 생성 및 할당하고 초기값을 명확히 세팅하여 실행 시점의 덤프 현상 조치 완료.
