## 1. 진행 내역
**[ ZFB1FI0002 ]** 자동 전표 생성 Function Module
- 공급업체 조달 프로세스 시 발생하는 전표가 자동 연동되도록 선선적입고 시점, 송장 시점, 지급 시점, 플랜트입고 시점으로 분기 조건을 세분화하여 로직을 구성하였다.

**[ ZRB1FI0001 ]** 전표 대시보드 프로그램
1) 전표 대시보드 프로그램을 module pool 프로그램에서 report 프로그램으로 변경하였다.
2) 전표 헤더 ALV, 전표 아이템 ALV 에 필요한 필드로만 구성한 structure 를 적용하였다.
3) Selection Screen 에서 회사코드 및 회계연도를 조건으로 입력하도록 구성하였고, 실행 시 해당 조건에 부합하는 데이터를 전표 헤더 ALV에 바인딩하도록 구현하였다.
4) 세부 전표 조회 버튼을 누르면 상세조건들이 있는 서브스크린이 동적으로 호출 및 종료되도록 프로세스를 구축하였다.
5) 서브스크린 호출 시 Selection Screen에서 선행 입력된 회사코드와 회계연도 데이터가 PBO 단을 통해 비활성화 필드로 자동 연동되도록 구성하였다.
6) 전표 아이템 ALV 내에서 차변과 대변이 구분되도록 LVC_T_STYLE을 사용하여 셀 색상을 추가하였다.
7) 계정 유형 필드를 GET_DOMAIN_VALUES을 사용하여 텍스트 필드로 구성하였다.

### 📌 차후 추가 기능
- 화면 좌측 상단 버튼을 통한 구매·생산·판매 전표 CRU 프로그램으로 이동하는 기능 구현 예정
- 각 프로그램에서 수행된 전표 수정 및 수동 생성 전표 데이터의 실시간 대시보드 동기화 반영 예정

## 2. 발생한 기술적 오류 및 조치
- **오류 1**: 버튼을 누르면 특정 조건에 맞춰 서브스크린이 호출되어야 하나, 프로그램 실행과 동시에 서브스크린이 먼저 로드되며 시스템 덤프 예외 발생.
- **조치 1**: 공백 서브스크린을 사전에 생성한 뒤 초기 화면 실행 시에는 빈 스크린이 할당되도록 PBO 단에서 구성하여 덤프 오류 조치 완료.
