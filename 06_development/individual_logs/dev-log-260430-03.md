- 탭스트립 제어의 경우, (1) 110번 서브스크린은 기존 팝업 ALV를 수정하고 우측에 차트를 띄워 유종별 드롭다운을 통해 생산 후 연산품 수율을 조회하도록 하였으며, (2) 130번 서브스크린은 현재 계절 가중치가 반영된 원유 수율 데이터를 ALV와 차트로 동시 출력하도록 구현하였다.

- **04.30** – 통화 데이터 보정 및 전사 결재 시스템([ZTB1MM0008](../../04_design/table_specifications/01_MM_table_spec.md#ZTB1MM0008)) 연동 및 자동 채번 작업을 수행하였다.

**[ ZRB1MM0001 ]** 부피측정 프로그램 *(조회성으로 임시 유지)*

- **04.27** – Selection-Screen 설계 및 통합 헤더 아이템 데이터 조회를 구현하였다.
- 전사 물류 데이터 통합을 위해 구매([ZTB1MM0006](../../04_design/table_specifications/01_MM_table_spec.md#ZTB1MM0006)), 생산([ZTB1PP0013](../../04_design/table_specifications/02_PP_table_spec.md#ZTB1PP0013)), 판매([ZTB1SD0006](../../04_design/table_specifications/03_SD_table_spec.md#ZTB1SD0006)) 헤더 및 아이템 테이블을 하나의 공통 구조로 조회/매핑하는 통합 서브루틴을 설계하였다.

- 생산 모듈의 수량 필드(ORDQTY)가 음수면 원유 투입(GR), 양수면 산출물(GI)로 자동 텍스트 매핑하는 로직을 적용하였다.
- **04.28 / 04.29** – 기존 하이라키 ALV를 팝업으로 이동하고 스플리터 ALV를 활용하였으며, HTML Document Link를 활용한 Process Flow 구현 및 펑셔널 스펙서 작성을 진행하였다.
- 레이아웃은 Top: `CL_DD_DOCUMENT`로 만드는 프로세스 플로우(오더 -> 측정 -> 입출고), Middle: 선택된 오더의 헤더 정보 ALV, Bottom: 선택된 오더의 아이템 상세 정보 ALV 구조로 세분화하였다.
- `ADD_LINK`, `ADD_ICON` 직접 호출 방식을 통해 메서드 타입 충돌 오류를 회피하고, [오더 -> 부피측정 -> 입출고]로 이어지는 직관적인 상태 가이드 UI를 구축하였다.
- 동적 상세 조회(Drill-down) 기능을 구현하여, 더블클릭 이벤트 발생 시 ZDOCNO와 PROCESS 타입을 식별하고 모듈별(PO/SO/PrO) 상세 정보를 자동 SELECT 하도록 처리하였다.

## 2. 발생한 기술적 오류 및 조치
- **오류 1**: 화면 PBO 단계에서 차트 컨트롤러 객체가 인스턴스화되기 전 데이터 렌더링 메서드가 호출되어 시스템 덤프가 발생하는 현상 발생.
- **조치 1**: `IF go_chartall IS BOUND` 구문을 추가하여 객체 생성 여부를 확인한 후 메서드를 호출하도록 구조를 개선하여 조치함.
- **오류 2**: 차트 구현 중 최적화 테이블의 원유 코드와 자재 마스터의 자재 코드가 일치하지 않거나, 텍스트 필드 간 비교 로직으로 인해 차트 데이터가 '0'으로 집계되는 현상 발생.
- **조치 2**: 텍스트 비교 대신 자재 코드(MATNR) 및 원유 코드 간의 1:1 매칭으로 로직을 변경하고, 공급업체-원재료-수율 조건이 유기적으로 연동되도록 `READ TABLE` 조건문을 수정하여 조치함.
- **오류 3**: [ZTB1MM0020](../../04_design/table_specifications/01_MM_table_spec.md#ZTB1MM0020)(측정)에 데이터가 없으면 JOIN 결과에서 오더 아이템 자체가 누락되는 현상 발생.
- **조치 3**: LOOP를 돌며 process가 비어있는 행을 찾아 gt_head를 역참조(`Read Table`)하여 누락된 오더 정보를 강제 매핑함으로써 데이터 누락을 차단 조치함.
