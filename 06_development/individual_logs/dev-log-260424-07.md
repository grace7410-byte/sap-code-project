**[ SAPMZB1SD0002 ]** 대금 청구 프로그램 
- 출고된 건들에 대해서 청구 여부를 확인하고 신규 청구까지 진행해야하기 때문에 CDS View를 이용하였다.
- 출고조차 안된 출고건들은 상태필드 A, 출고는 됐지만 청구가 안된 건들은 W, 청구까지 완료된 건들은 B, 입금 완료된 건들은 C로 구분하였다.
- 상태필드가 W->B->C->A 순으로 정렬하고 그 중에서도 출고일이 제일 오래된 건을 오름차순 정렬하였다.
- 상태필드가 W인 건들에 대해서만 신규 청구 가능하게 예외처리 하였다.
- 신규 청구 시 청구번호 채번이 되면서 200 스크린 상세 조회 화면으로 이동할 수 있도록 구현하였다.
- 200 스크린에서는 출고된 아이템들에 대해서 가격이 어떻게 설정되었는지도 확인할 수 있다.

## 2. 발생한 기술적 오류 및 조치
- **오류 1**: 헤더 ALV를 클릭하면 헤더에 맞는 아이템 ALV를 뿌리는데 아이템이 없는 헤더를 클릭했을 때 Message Type E로 처리했을 때, 아이템이 있는 헤더를 클릭했을 시에는 정상적으로 아이템 ALV에 띄우는 게 아닌 프로그램이 종료되는 현상 발생.
- **조치 1**: Message Type E 대신 TYPE 'S' DISPLAY LIKE 'W'를 사용하여 프로그램이 강제 종료되는 에러 처리를 막음.
- **오류 2**: Textedit를 이용해서 작업 이력 박스를 구현하는 와중에 텍스트가 보여질 gt_text 테이블에는 제대로 값이 있는데 set_table_as_stream이 작동하지 않는 오류 발생.
- **조치 2**: gs_text type char255 / gt_text type standard table of string으로 선언한 상태에서 append gs_text to gt_text를 한 게 원인이었으며, 같은 string 타입이어도 두 변수의 타입이 완전히 똑같지 않아서 발생한 오류임을 확인하고 타입을 정합하여 해결하였음.
