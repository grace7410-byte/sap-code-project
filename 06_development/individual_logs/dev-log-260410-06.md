## 1. 진행 내역
- **04.08**: 서브스크린을 구성하여 SELECTION-SCREEN 으로 조회 조건(회사코드, 조회기간, 전표유형)을 입력할 수 있도록 구현하였다.
- **04.09**: Splitter Container를 활용하여 전표 헤더 ALV 와 전표 아이템 ALV 를 출력하였다. 회사코드(필수값) 입력 시 전표 헤더, 아이템 ALV 및 헤더 데이터가 출력되도록 하였으며, 전표유형 및 조회기간(선택값) 입력 시 해당 조건이 포함된 데이터가 조회되도록 구현하였다. 전표 헤더 데이터를 하나 선택 후 더블클릭 시 해당 아이템 내역이 화면에 출력되도록 구성하였다. 구매, 생산, 판매, 전체조회 필터를 설정하여 라디오버튼 선택 및 조회 조건 설정 시 해당되는 데이터만 필터링되어 출력되도록 조치하였다.
- **04.10**: 체크박스를 활용하여 역분개 전표만 출력되도록 제어하였고, 참조번호 입력 시 해당 전표만 출력되도록 로직을 추가하였다. 또한, 타 모듈 연계를 위해 자동 전표를 생성할 수 있는 Function Module 구현을 진행하였다.

### 📌 차후 추가 기능 및 프로그램

- 각각의 프로그램에서 전표 수정 및 생성된 내역이 실시간으로 반영되도록 로직을 보완할 예정이다.
- 조건에 따라 자동으로 분개 전표가 생성되도록 인터페이스를 확장할 예정이다.

## 2. 발생한 기술적 오류 및 조치
* **오류 1**: 조회 조건에 있는 전표 유형(PARAMETER) 미입력 시, 데이터 조회가 불가능한 현상 발생.
* **조치 1**: 전표 유형을 RANGE 변수로 선언하고 사용자가 입력한 값을 담은 후, SELECT 구문의 WHERE 조건절에서 IN 연산자를 사용하도록 변경하여 오류 조치 완료.
* **오류 2**: 전표 이동(전체/구매/판매/생산) 필터 조건과 조회 조건을 동시에 만족하는 데이터를 화면에 출력하는 과정에서 에러 발생.
* **조치 2**: 라디오버튼 선택 값에 따라 구분자를 서브루틴(Subroutine) 파라미터로 넘겨주어, 해당 범주(구매/판매/생산/전체)에 부합하는 데이터만 정확히 조회되도록 로직 수정 완료.
