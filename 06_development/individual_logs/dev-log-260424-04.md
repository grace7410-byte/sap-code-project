## 1. 진행 내역
**[ 계획오더 헤더-아이템 테이블 구조 최적화 ([ZTB1PP0013, ZTB1PP0014](../../04_design/table_specifications/02_PP_table_spec.md#ztb1pp0013)) ]**
- 13번(헤더) 테이블에 계획/오더 구분을 식별하기 위한 `PLNTY` 필드를 기본키(PK)로 지정하였다.
- 14번(아이템) 테이블에도 외래키 및 식별 관계 유지를 위해 `PLNTY` 필드를 PK에 추가하였다.
- 계획 생산과 실제 생산의 명확한 연계 및 구분을 위해 14번 테이블의 `REQTY` 필드명을 `POQTY`로 변경하고 `ACQTY` 필드를 삭제하였다.
- 이에 따라 관련 Data Element인 `ZEB1_PP_REQTY`와 `ZEB1_PP_ACQTY`를 삭제하고, 신규 도메인 반영을 위해 `ZEB1_PP_POQTY`를 생성하였다.
- 14번 테이블에서 불필요한 종료일자(`DATUB`) 필드를 구성에서 제외하였다.
- 14번 테이블의 BOM 관련 필드인 `STLNR`(BOM 번호)과 `STLKN`(BOM 노드) 항목은 13번 헤더 테이블에서 직접 조회가 가능하므로 중복 데이터 방지를 위해 삭제 조치하였다.
- 구조 변경 내역을 반영하여 PP 모듈 ERD 및 샘플 테스트 데이터 최신화 작업을 완료하였다.

**[ MRP(자재요구량계획) 프로그램 개발 ]**
- **PIR 데이터 기반 최소 원유 투입량 계산**
  - BOM, 자재, 공정, PIR 데이터를 유기적으로 연결한 `ZCDS_B1_PP_0008` CDS View를 활용하여 조회 로직을 구축하였다.
  - 정유 공정 특성을 반영하여 완제품에서 원재료 방향으로 역추적하는 'Fert → Roh' 역방향 연산을 통해 수요별 최소 원유 투입량을 계산하였다.
  - 정유 공정의 최소 생산 수량을 안정적으로 확보하기 위해 계산된 투입량 수치의 소수점 처리 방식을 반올림 대신 '올림'으로 처리하도록 구현하였다.
- **최소 원유 투입량 기반 BOM 전개**
  - 선행 계산된 산출식을 통해 자재별 원유 투입량 후보군 데이터를 생성하였다.
  - 생산 부족분이 발생하지 않도록 최저 수율을 기준으로 투입량을 결정해야 하므로, 산출된 후보군 중 '최대값'을 채택하는 제어 로직을 적용하였다.
  - 계산된 투입량을 내림차순으로 정렬한 뒤, 동일 기간 및 동일 투입 원유 항목에 대한 중복 데이터를 제거하는 클렌징 작업을 수행하였다.
  - 최종 결정된 최소 투입량을 기준으로 하위 레벨까지 자재명세서가 풀리도록 BOM 재귀 전개 로직을 구현하였다.
  - 완제품에 대한 직접적인 수요가 없더라도 정유 생산 공정 특성상 연산품(Co-product)이 동시 배출되므로, 연쇄 전개가 정상적으로 수행되도록 예외 처리를 반영하였다.

### 📌 차후 추가 기능 및 프로그램

## 2. 발생한 기술적 오류 및 조치
- **오류 1**: CDS View(`ZCDS_B1_PP_0008`) 내부에서 CASE-ELSE 구문을 사용하여 초기값을 0으로 지정하였으나, ABAP에서 Open SQL 쿼리를 통해 데이터를 호출할 때 해당 0 값들이 정상적으로 조회되지 않는 현상 발생.
- **조치 1**: 데이터베이스 상의 Null 처리 방식을 보완하기 위해 CDS View 내에서 `COALESCE` 함수를 사용하도록 수정하여, Null 발생 시 명시적인 숫자 0이 ABAP 스택으로 정상 전달되도록 조치 완료하였다.
- **오류 2**: 재고 데이터를 조회할 때 특정 정유 설비와 물리적으로 동일한 위치에 존재하는 저장 창고(LGORT)를 매핑하는 과정에서 프로그램 내 하드코딩이 필요한 문제 발생.
- **조치 2**: 소스코드 품질 저하를 방지하기 위해 모듈 담당자들과 논의를 거쳐 테이블 구조 수정을 요청하였으며, 설비 마스터 및 저장창고 관계를 유연하게 특정할 수 있는 관련 연관 필드를 추가하는 방식으로 조치 완료하였다.
