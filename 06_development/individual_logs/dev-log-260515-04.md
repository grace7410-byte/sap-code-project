## 2. 발생한 기술적 오류 및 조치

- **오류 1**: 목적 값을 찾아 트리 노드를 탐색하는 소스 코드가 필요 이상으로 복잡하게 구성되는 문제 발생
- **조치 1**: 내부 테이블(Internal Table)에 일자와 트리 노드 객체를 함께 담아 보관하는 전용 테이블을 구축하고, 이를 인덱스 테이블처럼 활용하여 탐색 구조를 단순화함

- **오류 2**: Domain 구조를 변경하고 DB 테이블을 업데이트했음에도 불구하고, 런타임 시 타입 관련 문제가 지속되어 데이터 생성이 불가능한 현상 발생
- **조치 2**: SAP 커맨드 창에 `/$sync` 명령어를 실행하여 변경된 딕셔너리 스펙이 시스템 버퍼에 즉각 동기화 및 적용되도록 조치함

- **오류 3**: COLLECT 구문을 사용하여 데이터를 집계하는 과정에서 시스템 덤프(DUMP) 오류가 발생함
- **조치 3**: TYPES로 테이블 타입을 정의할 때 `NON-UNIQUE KEY` 지정을 추가 선언하여 테이블 구조적 충돌을 해결함

- **오류 4**: 화면 내에 그래프(차트)를 여러 개 그리려고 시도할 때, 마지막에 생성된 그래프를 제외하고 나머지 이전 그래프들이 화면에 렌더링되지 않는 현상 발생
- **조치 4**: 그래픽 엔진을 독립된 별도의 객체로 각각 선언하여 개별적으로 사용함으로써 렌더링 충돌 문제를 해결함
