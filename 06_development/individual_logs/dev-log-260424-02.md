## 1. 진행 내역
기존에는 타 모듈의 데이터를 CO 테이블에 중복 기록/저장하는 구조였으나, 필요한 데이터는 타 모듈에서 직접 가져오고 CO 테이블은 본연의 데이터 제공에만 집중하도록 구조를 수정하였다. 이에 따라 예시 데이터와 개발 예정 프로그램들을 전면 재구성하였다. 이전 테이블 구조에서는 공정 기록 중복으로 인해 원가 분석을 위한 금액 추적이 어려웠기에, 테이블 재설계를 통해 전체적인 수정을 진행하였다.

**[ ZRB1CO0007 ] 공정 계획 / 실적 비교 프로그램**
- 이미 개발이 완료되었던 기존의 공정 계획 / 실적 비교 테이블이 비용적인 면을 집중적으로 비교하여 보여줄 수 있도록 로직을 수정하였다.
- 기존의 공정 계획 / 실적의 경우 각각의 원유 비용, 시간당 공정 비용 및 공정비, 기타 촉매비 등 타 모듈의 데이터를 가져와 금액으로 계산 및 비교를 진행하도록 수정하였다.
- UI 는 전체적으로 기존의 ZRB1CO0007 프로그램의 UI 를 유지했으나, ALV 영역에서 계획/실적 오더 번호가 타 모듈에서 업데이트될 경우 프로그램 내부에서 REFRESH(업데이트)를 누르면 기존에 추가되지 않았던 테이블 데이터가 등록 또는 업데이트되는 기능을 추가하였다.

**[ SAPMZB1CO0003 ] 원가 계산 및 등록 프로그램**
- 공정 실적 입력 프로그램(기존 CO02)을 원가 계산 및 등록 프로그램(신규 SAPMZB1CO0003)으로 수정하여 개발을 진행 중이다.
- 공정 코드를 입력하면 그 공정의 결과로 나온 완제품의 단위원가를 계산하고, 이후 ZTB1CO0007 테이블에 CRU 가능하도록 구성하였다.

### 📌 차후 추가 기능 및 프로그램
- **SAPMZB1CO0003**: DELETE 의 경우 구현이 불가능하여 만약 기존 데이터로 새로 등록할 경우 버전을 다르게 하여 추가 등록되는 방식으로 개발 예정
- 추후 ZB1CO0006 프로그램 공정 원가 매핑을 유지보수하고 연계할 예정
- 두 프로그램(ZRB1CO0007, SAPMZB1CO0003)을 통해 CRU 된 테이블 ZRB1CO0007 과 ZB1CO0008 데이터를 FIORI 에서 개발될 프로그램 수익성 분석 시점에 사용할 예정

## 2. 발생한 기술적 오류 및 조치
- **오류 1**: 실시간 업데이트의 경우 프로그램에 접속하여 REFRESH 를 누르지 않아도 자동으로 테이블에 업데이트되도록 구상하려 하였으나, 시간적 문제가 발생하는 현상 발생.
- **조치 1**: 제한된 시간으로 안정성 있게 구현하기엔 무리가 있을 거라 판단해, 프로그램 내부 최초 진입 시점과 REFRESH 버튼을 눌렀을 경우에 데이터가 추가 및 업데이트가 되는 방식을 채택하여 조치 완료.
