## 2. 발생한 기술적 오류 및 조치

- **오류 1**: FIORI UI 레이어의 애플리케이션 출력 화면 및 OData 데이터 통신 테스트 중, 특정 통화 금액 데이터 필드 후미에 시스템 소수점인 `.00` 부호가 무조건 강제 표기되어 회계 금액 데이터의 가독성을 심각하게 저해하는 결함 발생.
- **조치 1**: 데이터를 게이트웨이 세션으로 서빙하는 백엔드 비즈니스 로직 파이프라인 최종 단계에서, 통화 데이터 변환 표준 펑션 모듈인 `CURRENCY_AMOUNT_SAP_TO_DISPLAY`를 호출하도록 소스 코드를 구현함. 이를 통해 내부 버퍼 스펙의 소수점 명세를 강제 포맷팅 처리하여 정상적인 정수 금액 구조로 UI 화면에 깨끗하게 출력되도록 완벽히 조치함.
