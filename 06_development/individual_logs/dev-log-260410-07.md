## 1. 진행 내역
- 해당 프로그램을 통해서 판매오더에 대한 전체적인 상세 내역을 유기적으로 파악할 수 있도록 구현하였다.
1) 1000번 스크린(Screen)에서 특정 물류센터를 선택하고 실행하면, 해당 물류센터에 귀속된 판매오더 건들만 좌측 Tree 구조에 계층별로 표시되도록 구현하였다.
2) 1000번 스크린의 검색 조건들을 활성화하고, 사용자가 입력한 데이터 값의 유효성 체크 로직이 AT SELECTION-SCREEN 이벤트에서 실행된 후 후속 프로세스가 진행되도록 조치하였다.
3) 특정 판매오더 번호를 더블클릭하면, 해당 오더에 대한 상세 정보가 우측 메인 서브스크린을 통해 다이내믹하게 표시되도록 화면을 구성하였다.
4) 세부 아이템 항목들 또한 서브스크린 내에 ALV Grid 형태로 동적 출력하여 확인할 수 있도록 구현하였다.
5) 해당 판매오더에 대해 출고 프로세스가 완료되어 출고번호가 채번되었다면 하위 노드에 출고번호가 표시되고, 해당 출고 건에 대해 대금 청구까지 완료되었다면 출고번호 하위 노드에 누적되어 쌓이도록 Tree 아키텍처를 구성하였다.
6) 출고 및 대금 청구 단계까지 진행되지 않은 미완료 판매오더 건에 대해서는 ALV Toolbar 내에 '출고하기' 및 '청구하기' 버튼을 구현 완료하였으며, 클릭 시 해당 출고/청구 개별 프로그램으로 동적 이동하도록 인터페이스를 설계하였다.

### 📌 차후 추가 기능 및 프로그램
1) 청구번호 클릭 시 우측 서브스크린 내 ALV 화면에 소계(SUBTOTAL) 기능을 추가할 예정이며, 이를 위해 동적 ALV 변경 또는 필드 카탈로그(Field Catalog)를 다원화하여 적용시키는 방안을 검토 중이다.
2) 판매오더 번호 선택 후 Application Toolbar에 배치된 '판매분석' 버튼 클릭 시, 해당 거래에 대한 실시간 마진율을 산출하여 표시하는 기능을 구현할 계획이다 (신규 마진분석 프로그램을 연계 호출할지, 내부 로직으로 직접 계산할지는 정밀 검토 예정).
3) 1000번 스크린 최초 실행 시에는 좌측 Tree 구조만 활성화되고 우측 서브스크린 영역은 숨김 처리되며, Tree의 특정 Node를 더블클릭하는 시점에 우측 서브스크린이 동적으로 확장되어 화면에 동시 표시되도록 스크린 제어 로직을 보완할 예정이다.

## 2. 발생한 기술적 오류 및 조치
* **오류 1**: SAP Tree 구조의 고유 키 값인 `node_key`를 설정하는 과정에서 판매오더 아이템 테이블(Item Table)의 `vbeln` 필드를 기본 키로 지정함에 따라, 중복된 판매오더 번호가 다중 행으로 유입되어 고유성 손실로 인한 중복 오류 발생.
* **조치 1**: 단일 판매오더 헤더를 기준으로 고유한 `node_key` 값이 1:1 매핑되어 생성될 수 있도록, 아이템 레벨이 아닌 판매오더 헤더 테이블(Header Table)의 `vbeln` 필드를 참조 소스로 변경 지정하여 데이터 중복 생성 오류 원천 조치 완료.
