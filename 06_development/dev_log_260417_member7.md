## 1. 진행 내역
- 기존의 '판매오더 번호(최상위 노드) → 출고 번호 → 청구 번호' 구조로 짜여 있던 트리 노드를 'BP 이름 분류(최상위 노드) → BP 명 → 판매오더번호' 형태로 전면 재구성하였다.
- 판매오더 상태를 볼 수 있는 오더 상태 박스, BP 에 대한 정보를 볼 수 있는 BP 정보 박스, 판매오더 헤더 ALV, 판매오더 아이템 ALV로 서브스크린 레이아웃을 구성하였다.
- 오더 상태 박스에는 각 상태의 오더들이 몇 건씩 존재하는지 확인할 수 있도록 구현하였으며, 박스 안의 필드들을 선택하면 해당 오더 상태에 대한 판매오더 정보만 확인할 수 있도록 필터링하여 제어하였다.
- 헤더 ALV 상의 특정 판매오더 번호 라인을 클릭할 경우, 연관된 아이템 항목이 화면에 출력되도록 이벤트를 연동하였다.

### 📌 차후 추가 기능
- 출고 처리가 미완료된 판매오더 건들을 대상으로 '출고하기' 버튼 클릭 시 출고 프로그램으로 이동하는 기능 구현 예정

## 2. 발생한 기술적 오류 및 조치
- **오류 1**: 헤더 ALV 영역에서 필터 조건을 적용한 후 특정 행을 선택하여 아이템 ALV를 불러올 때 필터링된 데이터로 반영되지 않아, 선택한 판매오더에 대한 건이 아닌 다른 정보가 불러와지는 현상 발생.
- **조치 1**: 필터 로직을 탈 때마다 SQL SELECT 구문을 다시 호출한 뒤 화면을 리프레시하여 새롭게 뿌려주는 방식으로 정합성 확보 완료.
