## 2. 기술적 트러블슈팅
### 이슈: ALV 필터 적용 시 헤더-아이템 데이터 불일치 현상
- **현상**: 헤더 ALV에서 특정 조건으로 필터를 적용한 후 아이템 내역을 호출할 때, 선택한 판매오더가 아닌 다른 오더의 정보가 출력되는 오류 발생
- **원인**: 필터링된 화면의 인덱스와 백엔드 내부 테이블(Internal Table)의 인덱스가 일치하지 않아 잘못된 행을 참조함
- **해결**: 필터 로직이 실행될 때마다 현재 선택된 행의 고유 키 값을 기반으로 `SELECT` 쿼리를 재수행하여 데이터를 새로 뿌려주는 방식으로 변경함으로써 데이터 정합성 확보
