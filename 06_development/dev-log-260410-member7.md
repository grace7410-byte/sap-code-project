## 2. 기술적 트러블슈팅
### 이슈: Tree 구조 생성 시 Node Key 중복 오류 발생
- **현상**: Tree 노드를 구성하는 과정에서 `node_key` 중복으로 인한 런타임 에러 발생 및 화면 출력 불가
- **원인**: 각 아이템별로 노드를 생성하면서 판매오더 아이템 테이블의 `VBELN` 필드를 키로 지정하여, 동일 오더 내 중복 키 발생
- **해결**: 하나의 판매오더가 고유한 노드를 가질 수 있도록 판매오더 헤더 테이블의 `VBELN` 필드를 `node_key`로 사용하여 중복 이슈 해결
