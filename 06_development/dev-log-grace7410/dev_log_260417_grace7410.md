## 2. 발생한 기술적 오류 및 조치
* **오류 1**: handle_data_changed 이벤트 내에서 화면 속성(SCREEN-INPUT) 변경 시, PBO 를 다시 타지 않아 비활성화 처리가 즉시 반영되지 않는 현상 발생.
* **조치 1**: 강제 PAI 호출(SET OK_CODE) 로 1 차 해결. 이후 데이터 변경 플래그를 활용하여 PBO 에서 화면 속성이 제어되도록 구조 개선.

* **오류 2**: 환율 데이터가 누락되어 원화 환산이 불가한 문제 발생.
* **조치 2**: CDS View 환율 유형(KURST) 필드의 데이터 타입과 조인 조건값('M')의 불일치임을 확인하여 수정함.

* **오류 3**: 사용자 정의 채번 로직(set_item_number)이 자동 호출되지 않아 아이템 번호가 갱신되지 않는 현상 발생.
* **조치 3**: after_user_command 등 표준 액션 이후 시점을 포착하여 채번 로직을 강제 수행함으로써 실시간 아이템 번호 정합성 확보.
