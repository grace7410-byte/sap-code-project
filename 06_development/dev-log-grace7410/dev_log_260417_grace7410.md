## 2. 기술적 트러블슈팅
### 이슈 1: `handle_data_changed` 내 화면 속성(SCREEN-INPUT) 변경 즉시 반영 불가
- **현상**: 데이터 변경 이벤트 발생 시 특정 필드를 비활성화하려 했으나, PBO를 다시 타지 않아 화면에 즉시 반영되지 않음
- **원인**: ALV 이벤트 내 로직은 화면 속성을 제어하는 PBO 사이클과 독립적으로 동작함
- **해결**: `SET OK_CODE`를 활용해 강제로 PAI를 호출하여 PBO가 재실행되도록 1차 조치 후, 데이터 변경 플래그를 활용해 PBO 내에서 화면 속성을 제어하는 방식으로 구조 개선

### 이슈 2: CDS View 조인 조건 불일치로 인한 환율 데이터 누락
- **현상**: 환율 정보를 조회하는 CDS View 연동 시 원화 환산 금액이 산출되지 않음
- **원인**: 환율 유형(KURST) 필드의 데이터 타입과 조인 조건으로 사용한 상수값('M') 간의 형식 불일치 확인
- **해결**: 조건값을 데이터 타입에 맞춰 수정하여 정확한 환율 데이터 호출 및 통화 변환 로직 정상화

### 이슈 3: 사용자 정의 채번(set_item_number) 로직 호출 시점 문제
- **현상**: 아이템 추가/변경 시 아이템 번호가 실시간으로 갱신되지 않음
- **원인**: 표준 ALV 액션 이후 채번 로직이 자동으로 호출되지 않아 데이터 정합성 불일치 발생
- **해결**: `after_user_command` 등 표준 액션 이후 시점을 포착하는 이벤트를 활용하여 채번 로직을 강제 수행함으로써 실시간 번호 정합성 확보
