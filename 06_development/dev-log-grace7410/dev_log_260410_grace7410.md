## 2. 기술적 트러블슈팅
### 이슈 1: 엔터 키 입력 시 이전 OK_CODE 잔상으로 인한 이벤트 중복 실행
- **현상**: 엔터 키 입력 시 메모리에 남은 이전 `OK_CODE`로 인해 구매오더 아이템 확장 등의 기능이 의도치 않게 반복 수행됨
- **원인**: `USER_COMMAND` 모듈 내 `OK_CODE` 초기화 시점 오류
- **해결**: `USER_COMMAND_0100` 모듈에서 `OK_CODE`를 로컬 변수에 보관한 즉시 원본을 `CLEAR` 처리하여 이벤트 중복 실행 제거

### 이슈 2: ALV 행 제어 시 아이템 번호 업데이트 지연
- **현상**: ALV 행 추가/삭제/복사 시 `set_item_number` 로직을 타도 화면상에 변경 전 번호가 유지되거나 공백으로 표시됨
- **원인**: 사용자 동작과 데이터 갱신 로직 간의 이벤트 우선순위 불일치
- **해결**: `lcl_event_handler`의 `on_after_user_command` 이벤트를 활용하여 동작 직후 `set_item_number`가 강제 실행되도록 우선순위 조정
