## 2. 기술적 트러블슈팅
### 이슈: 서브스크린 호출 시 초기 런타임 덤프(Runtime Error) 발생
- **현상**: 상세 조회 버튼 클릭 시에만 서브스크린이 나타나야 함에도 불구하고, 프로그램 실행 직후 서브스크린을 호출하려는 시도가 발생하며 시스템 덤프 발생
- **원인**: 서브스크린 영역(Subscreen Area)에 할당될 초기 화면 번호가 지정되지 않았거나, 이벤트 제어 로직 미비로 인해 빈 컨테이너를 호출함
- **해결**: 
    1. 아무런 로직이 없는 '빈 서브스크린(Empty Subscreen)' 화면을 별도로 생성
    2. 프로그램 초기값으로 해당 빈 화면 번호를 할당하여, 사용자가 버튼을 클릭하기 전까지는 오류 없이 대기 상태를 유지하도록 제어 구조 개선
