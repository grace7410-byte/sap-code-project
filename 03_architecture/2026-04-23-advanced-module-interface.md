### [MM-LE-FI] 서비스 PO 생성 및 데이터 흐름 인터페이스
* **프로세스 맵**: 일반 PO 가저장 -> 서비스 PO 데이터 결합 -> 최종 확정 시 통합 DB 적재.
* **트랜잭션 무결성 구조**: 
    1. 일반 PO 생성 중 가저장 플래그(`GV_SAVE_CHECK = 'X'`) 활성화 시, 구매오더 문서번호(`GV_EBELN`)를 참조 키로 획득 (메모리 유지).
    2. PBO 시점에 플래그 확인 후 하단 서비스 아이템 및 운송 경로 탭스트립 동적 팝업.
    3. 중간 취소 시 가저장된 ITAB 데이터 전체 롤백 처리(DB 저장 생략). SERVICE PO까지 확정되어야 기존 PO와 함께 최종 DB 테이블 인서트.

### [MM-PP] 생산 확정 기반 부피측정 및 입고 프로세스 연동
* **연동 개념**: PP 생산계획/오더 테이블의 오더량을 매핑하여 MM 부피측정 프로그램의 기준값으로 활용.
* **데이터 전제 조건**: 정유 공정 특성상 오더량과 실제 확정량이 상이할 수 있으나, 현재 시점에서는 공정 가동 전 인입 데이터인 '오더량'을 최종 확정량으로 간주하여 입고 데이터와 정합성을 매핑함.
